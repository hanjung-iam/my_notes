    重點摘要

    • Vertex cover：在最少的頂點放守衛，使每條邊（道路）都被保護。一般圖上非常難，目前沒有已知的多項式時間演算法。
    • 限制在樹上時，可以用 DP 在線性時間求出最少守衛數，再用 backtracking 求出擺放方式。
    • 只存子樹的最少守衛數 Best 不夠，還要存「根一定要放守衛」時的最少守衛數 Best1。
    • \(\text{Best1}(v)=1+\sum \text{Best}(c_i)\)；\(\text{Best}(v)=\min\{\sum \text{Best1}(c_i),\ \text{Best1}(v)\}\)。
    • 用 DFS 走訪，總時間 = 頂點數 + 邊數 = \(O(n)\)。

    1. Vertex Cover 問題

    • \(G\) 是一個無向圖。把頂點想成路口、邊想成道路。
    • 在頂點 \(v\) 放一個守衛，所有連到 \(v\) 的道路都會被保護。
    • 問題：最少要放幾個守衛，才能保護所有道路？
    📝
    例子 講義的範例圖中，可以放 4 個守衛保護所有道路，但最好的放法只需要 3 個。
    💡
    難度 一般情況下這個問題非常難，目前沒有已知的多項式時間演算法。但若把圖限制為樹，就能用 DP 在線性時間求出最少守衛數，再用 backtracking 求出擺放方式。

    Algo-Lecture-11.pdf p.3–6

    2. 樹上的 Vertex Cover

    倒著想

    令 \(T\) 為輸入的樹，先任選一個頂點當作根。假設已經知道每個子節點的子樹的最佳放法，能不能得到整棵 \(T\) 的最佳放法？

    ❗
    只知道子樹的最佳數量不夠 講義用兩個例子說明：兩棵子樹的 Best 都是 1，但整棵樹的最佳值一個是 3、一個是 2。問題在於子樹的最佳放法可能有、也可能沒有在子樹的根放守衛，這會造成很大的差別。

    多存一點資訊

    名稱意義
    Best子樹中最少要放幾個守衛
    Best1子樹中最少要放幾個守衛，但規定根一定要放守衛

    對一個有子節點 \(c_1,c_2,c_3,\dots\) 的頂點 \(v\)：

    \[\begin{aligned} \text{Best1}(v) &= 1+\text{Best}(c_1)+\text{Best}(c_2)+\text{Best}(c_3)+\cdots \\ \text{Best}(v) &= \min\{\text{Best1}(c_1)+\text{Best1}(c_2)+\text{Best1}(c_3)+\cdots,\ \ \text{Best1}(v)\} \end{aligned}\]
    📝
    例子（講義 Example Run）
    • 葉節點：Best = 0、Best1 = 1
    • 由下往上逐層計算，例如出現 (Best = 1, Best1 = 1)、(Best = 1, Best1 = 2) 等節點
    • 第一個範例樹的根：Best = 3、Best1 = 3；第二個範例樹的根：Best = 2、Best1 = 3
    （樹的形狀請見講義圖示。）

    Algo-Lecture-11.pdf p.7–19

    3. 執行時間與擺放方式

    • 用 Depth-First Search（線性時間）走訪 \(T\)；在 \(v\) 最後一次被拜訪時，就能算出 \(v\) 子樹的最少守衛數。
    • 花在頂點 \(v\) 的時間 = \(1+\) \(v\) 的子節點數
    • 總時間 = 頂點數 + 邊數 = \(O(n)\)
    • 守衛的實際擺放位置：用 backtracking 求出（講義以 p.21–25 的圖示逐步示範）。

    Algo-Lecture-11.pdf p.20–25

    4. 延伸：Greedy 與加權版本

    • 這個問題其實也可以用一個更簡單、完全不同的策略解決，稱為 greedy method。
    • 但 DP 的做法可以處理更一般的情況：若在不同頂點放守衛的成本不同，如何在樹上找出成本最小的擺放方式？（講義提問）

    自我測驗

    Q1. 一般圖上的 vertex cover 問題有多難？限制在樹上呢？

    一般圖上非常難，沒有已知的多項式時間演算法；限制在樹上時可以用 DP 在線性時間解出。

    Algo-Lecture-11.pdf p.6

    Q2. 為什麼只記錄子樹的 Best 不夠？

    子樹的最佳放法可能有、也可能沒有在子樹的根放守衛，這會影響父節點是否需要放守衛。

    Algo-Lecture-11.pdf p.10

    Q3. 寫出 Best1(v) 和 Best(v) 的遞迴式。

    \(\text{Best1}(v)=1+\sum_i \text{Best}(c_i)\)；\(\text{Best}(v)=\min\{\sum_i \text{Best1}(c_i),\ \text{Best1}(v)\}\)。

    Algo-Lecture-11.pdf p.12

    Q4. 葉節點的 Best 與 Best1 是多少？

    Best = 0、Best1 = 1。

    Algo-Lecture-11.pdf p.13

    Q5. 這個 DP 的總時間是多少？為什麼？

    \(O(n)\)。用 DFS 走訪，每個頂點花 \(1+\) 子節點數的時間，總和 = 頂點數 + 邊數。

    Algo-Lecture-11.pdf p.20
