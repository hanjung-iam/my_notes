    重點摘要

    • Subsequence：從字串刪掉一些字元、剩下的依序接起來；兩字串都有的 subsequence 稱為 common subsequence。
    • LLCS 遞迴：最後字元相同 → \(1+\) 兩者都去掉最後一字；不同 → 取「去掉 \(S\) 最後一字」與「去掉 \(T\) 最後一字」的最大值。
    • 填表求 LLCS：\(O(nm)\) 個值、每個 \(O(1)\) → 總時間 \(O(nm)\)。
    • 填表時順便記錄每格「從哪一格來」，最後 backtrack 就能找出一個 LCS。
    • 只求長度時，逐列填表可將空間降到 \(O(m)\)；Hirschberg (1975) 讓求 LCS 本身也只需 \(O(\min\{n,m\})\) 空間。

    1. 定義

    • Subsequence：從字串 \(S\) 刪除一些字元，再把剩下的字元依序接起來。
      例：\(S\) = abracadabra → “radar” 是 \(S\) 的 subsequence；\(S\) 本身也是。
    • Common subsequence：字串 \(W\) 同時是 \(S\) 和 \(T\) 的 subsequence。
      例：\(S\) = dirtyroom、\(T\) = dormitory → “dry” 是 common subsequence。
    • LCS (Longest Common Subsequence)：給定 \(S[1..n]\) 與 \(T[1..m]\)，最長的 common subsequence。

    做法：先用 DP 求出 LCS 的長度，再用 backtracking 輸出一個 LCS。

    Algo-Lecture-10.pdf p.3–5

    2. 求 LCS 的長度

    倒著想。令 \(\text{LLCS}(X,Y)\) = 字串 \(X\) 和 \(Y\) 的 LCS 長度，目標是 \(\text{LLCS}(S,T)\)。

    情況推論LLCS(S, T)
    \(S[n]=T[m]\)（同為 \(c\)） 一定存在某個以 \(c\) 結尾的 LCS → 把 \(S[n]\) 和 \(T[m]\) 配對，再求剩下的 LCS \(1+\text{LLCS}(S[1..n-1],T[1..m-1])\)
    \(S[n]\ne T[m]\) LCS 不以 \(S[n]\) 結尾，或不以 \(T[m]\) 結尾；不知道是哪一種，但取最大值一定正確 \(\max\{\text{LLCS}(S[1..n-1],T[1..m]),\ \text{LLCS}(S[1..n],T[1..m-1])\}\)
    💡
    一般化 對任何 \(i,j\)，\(\text{LLCS}(S[1..i],T[1..j])\) 可以由 \(\text{LLCS}(S[1..i-1],T[1..j-1])\)、\(\text{LLCS}(S[1..i-1],T[1..j])\)、\(\text{LLCS}(S[1..i],T[1..j-1])\) 算出，取決於 \(S[i]\) 和 \(T[j]\) 是否相同。
    📝
    例子：S = dirtyroom，T = dormitory 的 LLCS 表

    Step 1 先把第 0 列、第 0 行填 0；Step 2 再逐列 (\(i=1,2,\dots\)) 填入。

    DORMITORY
    0000000000
    D0111111111
    I0111122222
    R0112222233
    T0112223333
    Y0112223334
    R0112223344
    O0122223444
    O0122223444
    M0122333444
    右下角的值 = LCS 長度 = 4。（講義原圖的列是由下往上排，這裡改為由上往下。）

    時間：所有 \(i,j\) 共 \(O(nm)\) 個值，每個 \(O(1)\) → 總時間 \(O(nm)\)。

    Algo-Lecture-10.pdf p.6–16

    3. 找出 LCS 本身：Backtracking

    • 填 LLCS 表時，額外記錄每一格 \(\text{LLCS}(S[1..i],T[1..j])\) 是怎麼算出來的：
      • 來自 \(\text{LLCS}(S[1..i-1],T[1..j-1])\)？
      • 來自 \(\text{LLCS}(S[1..i],T[1..j-1])\)？
      • 來自 \(\text{LLCS}(S[1..i-1],T[1..j])\)？
    • 得到 \(\text{LLCS}(S,T)\) 之後，從右下角那一格開始，依這些資訊往回追 (backtrack)，就能取出一個 LCS。

    Algo-Lecture-10.pdf p.17–21

    4. 節省空間

    目標方法額外空間
    LLCS（基本做法）整張表\(O(nm)\)
    只求 LLCS逐列填表，每列只依賴正上方那一列\(O(m)\)（講義提問：能否只用 \(O(\min\{n,m\})\)？）
    求 LCS 本身Hirschberg (1975)\(O(\min\{n,m\})\)

    Hirschberg 的想法：找出把 \(T\) 切成兩段的最好方式，使第一段對應 \(S\) 的前半、第二段對應 \(S\) 的後半，再遞迴處理。

    Algo-Lecture-10.pdf p.22–23

    5. 編輯距離 (Edit Distance)

    給定 \(S[1..n]\) 和 \(T[1..m]\)，用一連串字元編輯操作把 \(S\) 轉成 \(T\)，求最少的操作次數。編輯操作有三種：

    1. Replace：把 \(S\) 的某個字元換成任意其他字元
    2. Insert：在 \(S\) 的某個位置插入一個字元
    3. Delete：從 \(S\) 刪除一個字元
    📝
    例子：S = practical，T = factual 可以用 4 次編輯操作把 \(S\) 轉成 \(T\)，對齊方式如下： 
    S = practical
T = f_actu_al

    解法：把 LCS 的方法稍微修改即可。講義留為習題：能否在 \(O(nm)\) 時間解出？能否只用 \(O(\min\{n,m\})\) 空間？

    Algo-Lecture-10.pdf p.24–26

    自我測驗

    Q1. 當 \(S[n]=T[m]\) 時，\(\text{LLCS}(S,T)\) 等於什麼？

    \(1+\text{LLCS}(S[1..n-1],T[1..m-1])\)。

    Algo-Lecture-10.pdf p.7

    Q2. 當 \(S[n]\ne T[m]\) 時，為什麼可以直接取 max？

    LCS 要嘛不以 \(S[n]\) 結尾、要嘛不以 \(T[m]\) 結尾；雖然不知道是哪一種，但取兩種情況的最大值永遠是正確的。

    Algo-Lecture-10.pdf p.8–9

    Q3. 求 LLCS 的時間複雜度？只求長度時空間可以降到多少？

    時間 \(O(nm)\)。逐列填表，每列只依賴上一列，空間可降到 \(O(m)\)。

    Algo-Lecture-10.pdf p.16, p.22

    Q4. 要輸出一個 LCS（不只是長度），填表時需要多記錄什麼？

    記錄每一格的值是由哪一格（左上、左、上）算出來的，最後從終點 backtrack 回去。

    Algo-Lecture-10.pdf p.17

    Q5. Edit distance 允許哪三種編輯操作？

    Replace（換掉一個字元）、Insert（插入一個字元）、Delete（刪除一個字元）。

    Algo-Lecture-10.pdf p.24
