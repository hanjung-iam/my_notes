    重點摘要

    • 圖的表示：Adjacency List 空間 \(O(|V|+|E|)\)、列舉鄰居快；Adjacency Matrix 空間 \(O(|V|^2)\)、檢查兩點是否相鄰快。
    • BFS：從 source \(s\) 一輪一輪探索，第 \(k\) 輪 discover 與 \(s\) 距離為 \(k\) 的頂點。
    • 正確性：距離為 \(k\) 的頂點一定有距離為 \(k-1\) 的鄰居 → \(v\) 在第 \(k\) 輪被 discover ⇔ 距離為 \(k\)。
    • 時間 \(O(|V|+|E|)\)；可以用一個共用的 queue 實作；也可以用來找出所有 connected components。
    • BFS tree 之外的邊（directed）分為 back edge、forward edge、cross edge。

    1. 圖的表示

    Graph 由 vertices 與 edges 組成，分為 undirected 與 directed 兩種。

    Adjacency List

    每個頂點 \(v\) 用一個 list 存它所有的鄰居。

    📝
    例子（undirected） 1: 2, 5　2: 1, 3　3: 2, 5　4: 3, 5　5: 1, 3（講義 p.4 的圖）

    Adjacency Matrix

    用 \(|V|\times|V|\) 的矩陣 \(A\)：若 \((u,v)\) 是一條邊則 \(A(u,v)=1\)，否則 \(A(u,v)=0\)。

    Adjacency ListAdjacency Matrix
    空間\(O(|V|+|E|)\)：\(|E|\) 小時很好\(O(|V|^2)\)：\(|E|\) 小時不好
    列舉某頂點的所有鄰居有效率慢
    檢查兩頂點是否相鄰慢快
    表示 weighted graph可以可以

    Algo-Lecture-22_241204_155121.pdf p.3–9

    2. Breadth-First Search

    一個簡單的方法，找出從 source \(s\) 可以到達的所有頂點。想法：一輪一輪探索圖，第 \(k\) 輪 discover 與 \(s\) 距離為 \(k\) 的頂點。

    BFS1. Mark s as discovered in round 0
2. for ( round k = 1, 2, 3, … )
       for ( each vertex u discovered in round k–1 )
           Mark u as visited;
           for ( each neighbor v of u )
               if ( v is not visited and not discovered )
                   Mark v as discovered in round k;
   Stop when no vertices are discovered in round k-1
    • 沒有新節點被 discover 時就結束。
    • Discover 新節點時的邊方向形成一棵樹，包含所有從 \(s\) 可到達的節點 → 稱為 \(s\) 的 BFS tree。

    Algo-Lecture-22_241204_155121.pdf p.10–15

    正確性

    💡
    觀察 若頂點 \(v\) 與 \(s\) 的距離為 \(k\)，則 \(v\) 一定有某個鄰居 \(u\) 與 \(s\) 的距離為 \(k-1\)。
    → 由歸納法：\(v\) 在第 \(k\) 輪被 discover ⇔ \(v\) 與 \(s\) 的距離為 \(k\)。

    Algo-Lecture-22_241204_155121.pdf p.16

    實作與時間

    • 用一個 \(O(|V|)\) 大小的陣列記錄每個頂點的 discovered／visited 狀態。
    • 用另一個 list 維護每一輪 discover 的頂點。
    • 每個頂點最多被 discover 一次、每條邊最多被看兩次 → \(O(|V|+|E|)\)。
    • 也可以不分輪，改用一個共用的 queue \(Q\)：\(Q\) 不空時從前端取出頂點來 visit（並 discover 它的鄰居）；頂點被 discover 時插到 \(Q\) 的尾端。時間、空間都沒有改進，但方法更簡單，不需要維護「輪」。

    Algo-Lecture-22_241204_155121.pdf p.17–18

    找出所有 Connected Components

    Pseudocodefor ( each vertex u )
    if ( u is not visited )
        Run BFS with u as source;

    每跑一次 BFS 就找到一個新的 component；時間與該 component 的邊數成正比 → 總共 \(O(|V|+|E|)\)。

    Algo-Lecture-22_241204_155121.pdf p.19

    3. 邊的分類 (Lecture 22S)

    BFS 結束後得到以 \(s\) 為 root 的 BFS tree \(T\)：\(u\) 是 \(v\) 的 parent ⇔ BFS 中 \(u\) discover \(v\)。\(T\) 中的邊稱為 tree edges。

    當 \(G\) 是 directed 時，非 tree edge \((u,v)\) 分成三類：

    類型條件
    Back edge\(v\) 是 \(u\) 在 \(T\) 中的 ancestor
    Forward edge\(u\) 是 \(v\) 在 \(T\) 中的 ancestor
    Cross edge其他（\(u\)、\(v\) 在 \(T\) 中沒有 ancestor–descendant 關係）
    • 當 \(G\) 是 undirected 時：若 \(u\) 比 \(v\) 先探索邊 \(\{u,v\}\)，就把它定向為 \((u,v)\) → 每條邊變成有向，再依 directed 的方式分類。
    • 講義的思考題：假設 \(G\) 是 undirected 且 connected，可能有 back edge 嗎？（講義沒有給出答案。）
    • 之後介紹的 DFS 也會定義 DFS tree，並用完全相同的方式把邊分成 tree、back、forward、cross edges。

    Algo-Lecture-22S_241204_153113.pdf p.3–7

    自我測驗

    Q1. Adjacency list 與 adjacency matrix 各適合什麼情況？

    Adjacency list 空間 \(O(|V|+|E|)\)，邊少時很好、列舉鄰居快；adjacency matrix 空間 \(O(|V|^2)\)，但檢查兩點是否相鄰很快。

    Algo-Lecture-22_241204_155121.pdf p.6, p.9

    Q2. BFS 第 \(k\) 輪 discover 哪些頂點？為什麼正確？

    與 \(s\) 距離為 \(k\) 的頂點。因為距離為 \(k\) 的頂點一定有距離為 \(k-1\) 的鄰居，由歸納法可得。

    Algo-Lecture-22_241204_155121.pdf p.10, p.16

    Q3. BFS 的時間為什麼是 \(O(|V|+|E|)\)？

    每個頂點最多被 discover 一次，每條邊最多被看兩次。

    Algo-Lecture-22_241204_155121.pdf p.17

    Q4. 用 queue 實作 BFS 時，頂點何時插入、何時取出？

    頂點被 discover 時插到 \(Q\) 尾端；\(Q\) 不空時從前端取出頂點來 visit 並 discover 它的鄰居。

    Algo-Lecture-22_241204_155121.pdf p.18

    Q5. Directed graph 中，非 tree edge \((u,v)\) 的三種分類是什麼？

    Back edge：\(v\) 是 \(u\) 的 ancestor；Forward edge：\(u\) 是 \(v\) 的 ancestor；Cross edge：兩者沒有 ancestor–descendant 關係。

    Algo-Lecture-22S_241204_153113.pdf p.4
