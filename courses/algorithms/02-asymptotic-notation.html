    複雜度分析

    重點摘要

    • 比較執行時間時只看主導項 (dominating term)，連主導項的常數也可以忽略 → \(n^2\) vs \(n\log n\)。
    • \(O\) 像 \(\le\)、\(\Omega\) 像 \(\ge\)、\(\Theta\) 像 \(=\)、\(o\) 像 \(<\)、\(\omega\) 像 \(>\)。
    • \(f(n)=O(g(n))\iff g(n)=\Omega(f(n))\)；\(f(n)=\Theta(g(n))\iff f(n)=O(g(n))\) 且 \(f(n)=\Omega(g(n))\)。
    • Little-o 等價定義：\(\lim_{n\to\infty} f(n)/g(n)=0\)；Little-omega：\(\lim_{n\to\infty} g(n)/f(n)=0\)。
    • Insertion Sort = \(\Theta(n^2)\)，Merge Sort = \(\Theta(n\log n)\)（沒特別說明時，執行時間指 worst-case）。

    1. 主導項與漸進效率

    • Insertion Sort 的執行時間 \(An^2+Bn+C\)；Merge Sort 的執行時間 \(Dn\log n+En+F\)（\(A\)–\(F\) 為常數）。
    • \(n\) 很大時，只要看主導項（\(n\) 增加時成長最快的項）：\(An^2\) vs \(Dn\log n\)。
    • 主導項的常數影響不大 → 直接比較 \(n^2\) vs \(n\log n\) → \(n\) 夠大時 Merge Sort 比 Insertion Sort 好。
    • 這種比較稱為研究兩個演算法的 asymptotic efficiency；若 P 比 Q asymptotically faster，P 通常是較好的選擇。

    手寫筆記：漸進符號用來描述函數的成長。例：\(F(n)=2n^3+4n-5\) 成長得像 \(n^3\) → \(F(n)=O(n^3)\)（order）。

    lecture2_241017_175628.pdf p.3–5；手寫筆記_Sorting_DP.pdf p.3

    2. Big-O

    給定 \(g(n)\)，\(O(g(n))\) 是下列函數的集合：

    \[O(g(n))=\{\,f(n)\mid \exists\ c,n_0>0 \text{ such that } 0\le f(n)\le c\,g(n)\ \ \forall n\ge n_0\,\}\]

    大意：\(O(g(n))\) 包含所有被 \(g(n)\) 上界住的函數。習慣上寫 \(f(n)=O(g(n))\) 來表示 \(f(n)\in O(g(n))\)。

    例子證明
    \(4n\in O(5n)\)\(c=1,\ n\ge 1\)
    \(4n\in O(n)\)\(c=4,\ n\ge 1\)
    \(4n+3\in O(n)\)\(c=5,\ n\ge 3\)
    \(n\in O(0.001n^2)\)\(c=1,\ n\ge 100\)
    \(\log_e n\in O(\log n)\)\(c=1,\ n\ge 1\)
    \(\log n\in O(\log_e n)\)\(c=\log e,\ n\ge 1\)

    lecture2_241017_175628.pdf p.6–7

    3. Big-Omega

    \[\Omega(g(n))=\{\,f(n)\mid \exists\ c,n_0>0 \text{ such that } 0\le c\,g(n)\le f(n)\ \ \forall n\ge n_0\,\}\]

    大意：\(\Omega(g(n))\) 包含所有被 \(g(n)\) 下界住的函數。

    💡
    Big-O 與 Big-Ω 的關係 \(f(n)=O(g(n))\iff g(n)=\Omega(f(n))\)
    例子證明
    \(5n=\Omega(4n)\)\(c=1,\ n\ge 1\)
    \(n=\Omega(4n)\)\(c=1/4,\ n\ge 1\)
    \(4n+3=\Omega(n)\)\(c=1,\ n\ge 1\)
    \(0.001n^2=\Omega(n)\)\(c=1,\ n\ge 100\)
    \(\log_e n=\Omega(\log n)\)\(c=1/\log e,\ n\ge 1\)
    \(\log n=\Omega(\log_e n)\)\(c=1,\ n\ge 1\)

    手寫筆記的例子：\(F(n)=2n^3+4n-5\) → \(F(n)=O(n^3)\)，也可以寫 \(F(n)=\Omega(n^2)\)。

    lecture2_241017_175628.pdf p.8–10；手寫筆記_Sorting_DP.pdf p.3

    4. Theta

    \[\Theta(g(n))=\{\,f(n)\mid \exists\ c_1,c_2,n_0>0 \text{ such that } 0\le c_1g(n)\le f(n)\le c_2g(n)\ \ \forall n\ge n_0\,\}\]

    意思：同時可以被 \(g(n)\) 上界和下界住的函數，也就是 \(\Theta(g(n))=O(g(n))\cap\Omega(g(n))\)。

    💡
    三者的關係 \(f(n)=\Theta(g(n))\iff f(n)=O(g(n))\) 且 \(f(n)=\Omega(g(n))\)
    例子證明
    \(4n=\Theta(n)\)\(c_1=1,\ c_2=4,\ n\ge 1\)
    \(4n+3=\Theta(n)\)\(c_1=1,\ c_2=5,\ n\ge 3\)
    \(\log_e n=\Theta(\log n)\)\(c_1=1/\log e,\ c_2=1,\ n\ge 1\)
    • Running time of Insertion Sort = \(\Theta(n^2)\)；沒特別說明時，running time 指 worst-case。
    • Running time of Merge Sort = \(\Theta(n\log n)\)。
    ⚠️
    待確認 手寫筆記 p.3 對 \(\lg_e n=\Theta(\lg n)\) 寫的不等式是「\(\lg n\le \lg_e n\le \frac{\lg n}{\lg e}\)」（並在旁註「相等」），講義 p.13 用的常數是 \(c_1=1/\log e,\ c_2=1\)。兩者寫法不同，請對照確認。

    lecture2_241017_175628.pdf p.11–13；手寫筆記_Sorting_DP.pdf p.3

    5. Little-o 與 Little-omega

    Little-o

    \[o(g(n))=\{\,f(n)\mid \forall c>0,\ \exists\ n_0>0 \text{ such that } 0\le f(n)<c\,g(n)\ \ \forall n\ge n_0\,\}\]

    注意和 Big-O 的異同：Big-O 是「存在某個 \(c\)」，little-o 是「對任意 \(c\)」。等價定義：

    \[o(g(n))=\{\,f(n)\mid \lim_{n\to\infty} f(n)/g(n)=0\,\}\]

    例：\(4n=o(n^2)\)、\(n\log n=o(n^{1.000001})\)、\(n\log n=o(n\log^2 n)\)。

    📝
    例子（手寫筆記，用極限證明） \(\ln n=o(n)\)：\(\displaystyle\lim_{n\to\infty}\frac{\ln n}{n}=\lim_{n\to\infty}\frac{1/n}{1}=0\)
    \(\ln n=o(n^{\varepsilon})\)：\(\displaystyle\lim_{n\to\infty}\frac{\ln n}{n^{\varepsilon}}=\lim_{n\to\infty}\frac{1/n}{\varepsilon n^{\varepsilon-1}}=\lim_{n\to\infty}\frac{1}{\varepsilon n^{\varepsilon}}=0\)

    Little-omega

    \[\omega(g(n))=\{\,f(n)\mid \forall c>0,\ \exists\ n_0>0 \text{ such that } 0\le c\,g(n)<f(n)\ \ \forall n\ge n_0\,\}\]

    等價定義：\(\omega(g(n))=\{\,f(n)\mid \lim_{n\to\infty} g(n)/f(n)=0\,\}\)。

    💡
    Little-o 與 Little-ω 的關係 \(f(n)=o(g(n))\iff g(n)=\omega(f(n))\)

    lecture2_241017_175628.pdf p.14–17；手寫筆記_Sorting_DP.pdf p.3

    6. 記憶方式

    符號像意思
    \(O\)\(\le\)\(f(n)=O(g(n))\) means \(f(n)\le cg(n)\)
    \(\Omega\)\(\ge\)\(f(n)=\Omega(g(n))\) means \(f(n)\ge cg(n)\)
    \(\Theta\)\(=\)\(f(n)=\Theta(g(n))\iff g(n)=\Theta(f(n))\)
    \(o\)\(<\)\(f(n)=o(g(n))\) means \(f(n)<cg(n)\)
    \(\omega\)\(>\)\(f(n)=\omega(g(n))\) means \(f(n)>cg(n)\)
    ❗
    易錯：不是任兩個函數都能比較 例如 \(\sin x\) 和 \(\cos x\) 無法用漸進符號比較。

    lecture2_241017_175628.pdf p.18；手寫筆記_Sorting_DP.pdf p.4

    7. 找錯：\(1+2+\dots+n=O(n)\)？

    講義的思考題：有人用數學歸納法「證明」\(1+2+\dots+n=O(n)\)：

    1. First, \(1=O(n)\)
    2. Assume \(1+2+\dots+k=O(n)\)
    3. Then, \(1+2+\dots+k+(k+1)=O(n)+(k+1)=O(n)+O(n)=O(2n)=O(n)\)

    講義問：bug 在哪裡？（講義沒有給出答案。）

    自我測驗

    Q1. 寫出 Big-O 的定義。

    \(O(g(n))=\{f(n)\mid\) 存在正常數 \(c,n_0\)，使得對所有 \(n\ge n_0\)，\(0\le f(n)\le cg(n)\}\)。

    lecture2_241017_175628.pdf p.6

    Q2. 證明 \(4n+3=\Theta(n)\) 時要用哪些常數？

    \(c_1=1,\ c_2=5,\ n\ge 3\)。

    lecture2_241017_175628.pdf p.13

    Q3. Little-o 和 Big-O 的定義差在哪裡？

    Big-O 只要存在某個正常數 \(c\)；little-o 要求對任意正常數 \(c\) 都存在 \(n_0\) 使 \(f(n)<cg(n)\)。等價於 \(\lim f(n)/g(n)=0\)。

    lecture2_241017_175628.pdf p.14–15

    Q4. \(f(n)=\Theta(g(n))\) 和 Big-O、Big-Ω 有什麼關係？

    \(f(n)=\Theta(g(n))\iff f(n)=O(g(n))\) 且 \(f(n)=\Omega(g(n))\)。

    lecture2_241017_175628.pdf p.12

    Q5. 用極限說明 \(\ln n=o(n)\)。

    \(\lim_{n\to\infty}\frac{\ln n}{n}=\lim_{n\to\infty}\frac{1/n}{1}=0\)，所以 \(\ln n=o(n)\)。

    手寫筆記_Sorting_DP.pdf p.3
