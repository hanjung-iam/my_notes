    堆積

    重點摘要

    • Binary heap 很難把兩個 heap 合併；Binomial Heap 支援有效率的 Union，每個操作仍是 \(O(\log n)\)。
    • Binomial tree \(B_k\)：\(B_0\) 是單一節點；\(B_k\) 由兩棵 \(B_{k-1}\) 連接而成（一個 root 變成另一個 root 的 leftmost child）。
    • \(B_k\) 有 \(2^k\) 個節點、高度 \(k\)、root 的 degree 為 \(k\)、第 \(j\) 層有 \(\binom{k}{j}\) 個節點。
    • 每種 order 最多一棵 \(B_k\) → 組成方式對應 \(n\) 的二進位表示，最多 \(O(\log n)\) 棵樹。
    • Union 像二進位加法；Insert = 和只有一個 \(B_0\) 的 heap 做 Union；Delete = Decrease-Key 到 \(-\infty\) 再 Extract-Min。

    1. 為什麼需要 Binomial Heap

    • Binary heap 支援有效率的 Insert、Extract-Min，也支援 Decrease-Key（把某個項目的值改小）；\(n\) 個項目時每個操作 \(O(\log n)\)。
    • 但有兩個 binary heap 時，很難把它們的項目合併成一個 heap。
    • Binomial Heap 是更有彈性的 heap，支援合併兩個 heap（Union），每個操作仍是 \(O(\log n)\)。
    • 它不是只用一棵樹，而是維護最多 \(O(\log n)\) 棵樹 → 更有彈性。

    Algo-Lecture-17_241127_151056.pdf p.3–4；手寫筆記_binomial heap.pdf p.1

    2. Binomial Tree

    Binomial Heap 中的每棵 component tree 都是 binomial tree。Order 為 \(k\) 的 binomial tree \(B_k\)：

    • \(B_0\) 是只有一個節點的樹。
    • \(k>0\) 時，\(B_k\) 由兩棵 \(B_{k-1}\) 連接而成：其中一棵的 root 變成另一棵 root 的 leftmost child。
    💡
    Lemma（證明用數學歸納法） 對 order 為 \(k\) 的 binomial tree \(B_k\)：
    • 節點數 \(=2^k\)，高度 \(=k\)，root 的 degree \(=k\)
    • root 的子樹由左到右剛好是 \(B_{k-1},B_{k-2},\dots,B_0\)
    • 第 \(j\) 層剛好有 \(\binom{k}{j}\) 個節點
    📝
    例子（手寫筆記） \(B_3\)：第 1 層有 \(\binom{3}{1}=3\) 個節點，第 2 層有 \(\binom{3}{2}=3\) 個節點。

    Algo-Lecture-17_241127_151056.pdf p.5–7；手寫筆記_binomial heap.pdf p.1

    3. Binomial Heap 的定義

    • 有 \(n\) 個項目的 Binomial Heap 由一組 binomial tree 組成，一個節點對應一個項目。
    • 每棵 binomial tree 中的節點滿足 heap property：\(\text{value}(u)>\text{value}(\text{parent}(u))\)。
    • 每個 \(k\) 最多一棵 \(B_k\) → component tree 是唯一的，對應 \(n\) 的二進位表示。
    📝
    例子 \(13=1101_{(2)}\) → 由 \(B_3\)、\(B_2\)、\(B_0\) 組成：\(B_0\) = {12}；\(B_2\) 的 root 為 8（子節點 25、13，25 下有 41）；\(B_3\) 的 root 為 15（子節點 19、32、16…）。

    Algo-Lecture-17_241127_151056.pdf p.8–9；手寫筆記_binomial heap.pdf p.1

    4. 操作

    Find-Min 與 Decrease-Key

    • Heap 中有 \(O(\log n)\) 棵樹 → Find-Min 檢查每棵樹的 root → \(O(\log n)\)；若維護一個 minimum pointer → \(O(1)\)。
    • 每棵 \(B_k\) 的 \(k=O(\log n)\) → Decrease-Key 反覆把節點和 parent 交換來修正 heap property → \(O(\text{tree height})=O(\log n)\)。

    Algo-Lecture-17_241127_151056.pdf p.10；手寫筆記_binomial heap.pdf p.2

    Union

    • 合併 \(H_1\) 與 \(H_2\)：依 order 由小到大處理 component trees。
    • 遇到兩棵 order 相同的 \(B_k\)，就把它們的 root 連起來形成 \(B_{k+1}\)；兩個 root 中值較小的成為新的 root。
    • 假設每個 heap 的 component tree 依 order 由小到大排好 → Union 花 \(O(\log n)\)（類比二進位加法）。
    📝
    例子：Union 5 個節點與 13 個節點的 heap \(H_1\)：\(B_0\)={12}、\(B_2\)(root 8)、\(B_3\)(root 15)；\(H_2\)：\(B_0\)={4}、\(B_2\)(root 9)。
    1. k = 0：連接兩棵 \(B_0\) → \(B_1\)（root 4，child 12）
    2. k = 2：連接兩棵 \(B_2\)（root 8 與 9）→ \(B_3\)（root 8）
    3. k = 3：連接兩棵 \(B_3\)（root 8 與 15）→ \(B_4\)（root 8）
    結果：\(B_1\)(root 4) 與 \(B_4\)(root 8)。
    ⚠️
    待確認 手寫筆記 p.2–3 的 Union 例子中，\(H_1\) 的 \(B_3\) root 在原圖寫 15，但在「1. link \(B_0\)」之後的圖寫成 13，「3. link \(B_3\)」的結果把 13 畫在 \(B_4\) 的 root；講義 p.15 的結果是 root 為 8。上方依講義整理。

    Algo-Lecture-17_241127_151056.pdf p.11–16；手寫筆記_binomial heap.pdf p.2–3

    Insert

    建立只含一棵 \(B_0\)（存 \(x\)）的 heap \(H'\)，再把 \(H\) 與 \(H'\) 做 Union → \(O(\log n)\)。

    Algo-Lecture-17_241127_151056.pdf p.16；手寫筆記_binomial heap.pdf p.2

    Extract-Min

    Extract-Min(H)1. Find the tree Bj containing the minimum
2. Detach Bj from H, so that H becomes H1
3. Remove root from Bj, so that it becomes H2
   (with j component trees)
4. Union H1 with H2

    → \(O(\log n)\)。

    📝
    例子（13 個節點的 heap） 最小值 8 在 \(B_2\) → \(H_1\) = {12}、\(B_3\)(root 15)；移除 8 後 \(H_2\) = {25–41}、{13}。Union：先連接兩棵 \(B_0\)（12、13）→ \(B_1\)(root 12)；再連接兩棵 \(B_1\)（12 與 25）→ \(B_2\)(root 12)。結果：\(B_2\)(root 12) 與 \(B_3\)(root 15)。

    Algo-Lecture-17_241127_151056.pdf p.17–20；手寫筆記_binomial heap.pdf p.3

    Delete

    1. 對 \(x\) 做 Decrease-Key，把值設為 \(-\infty\)；
    2. 做 Extract-Min。

    → \(O(\log n)\)。

    Algo-Lecture-17_241127_151056.pdf p.21；手寫筆記_binomial heap.pdf p.3

    5. 操作時間整理

    操作時間說明
    Find-Min\(O(\log n)\)／\(O(1)\)檢查每棵樹的 root；維護 minimum pointer 時為 \(O(1)\)
    Insert\(O(\log n)\)和單一 \(B_0\) 做 Union
    Decrease-Key\(O(\log n)\)和 parent 反覆交換
    Union\(O(\log n)\)同 order 的樹兩兩連接
    Extract-Min\(O(\log n)\)拆出 \(B_j\)、移除 root、再 Union
    Delete\(O(\log n)\)Decrease-Key 到 \(-\infty\) + Extract-Min

    Algo-Lecture-17_241127_151056.pdf p.10, p.16–17, p.21；手寫筆記_binomial heap.pdf p.2–3

    自我測驗

    Q1. \(B_k\) 是怎麼由較小的 binomial tree 組成的？

    由兩棵 \(B_{k-1}\) 連接而成，一棵的 root 成為另一棵 root 的 leftmost child。

    Algo-Lecture-17_241127_151056.pdf p.5

    Q2. \(B_k\) 有幾個節點？高度、root 的 degree 是多少？第 \(j\) 層有幾個節點？

    \(2^k\) 個節點、高度 \(k\)、root degree \(k\)、第 \(j\) 層有 \(\binom{k}{j}\) 個節點。

    Algo-Lecture-17_241127_151056.pdf p.7

    Q3. 有 13 個項目的 binomial heap 由哪些 binomial tree 組成？為什麼？

    \(13=1101_{(2)}\)，所以由 \(B_3\)、\(B_2\)、\(B_0\) 組成；每種 order 最多一棵，組成方式對應 \(n\) 的二進位表示。

    Algo-Lecture-17_241127_151056.pdf p.8–9

    Q4. Union 時遇到兩棵相同 order 的 \(B_k\) 要怎麼做？

    把兩個 root 連起來形成 \(B_{k+1}\)，值較小的 root 成為新的 root。

    Algo-Lecture-17_241127_151056.pdf p.11

    Q5. 如何用其他操作完成 Delete？

    先對 \(x\) 做 Decrease-Key 把值設成 \(-\infty\)，再做 Extract-Min，共 \(O(\log n)\)。

    Algo-Lecture-17_241127_151056.pdf p.21
