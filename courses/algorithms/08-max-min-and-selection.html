    找最大最小值與第 k 小 (Max, Min & Selection)

    下界 選擇問題

    重點摘要

    • 找最大值需要 \(n-1\) 次比較，而且這是下界：每個非最大值的數都必須輸一次，每次比較只產生一個輸家。
    • 同時找最大與最小值：兩兩配對後，大的找 max、小的找 min，只要 \(1.5n-2\) 次比較（\(n\) 為偶數），這也是下界。
    • 下界的證明方法：對手論證（邊執行邊決定比較結果），用紅球／藍球追蹤每個人還可能是 max 或 min。
    • 找第 \(k\) 小：用 Quicksort 的 partition 縮小問題；隨機 pivot 的期望時間為 \(\Theta(n)\)。
    • 用 median of medians 當 pivot，兩邊大小都 \(\le 3n/4\)，worst case 為 \(\Theta(n)\)。

    1. 找最大值 (Finding Max)

    Method IStep 1: Set max as S[1];
Step 2: for (k = 2, 3, 4, ..., n)
            if (S[k] > max)
                Update max as S[k];
Step 3: return max;

    比較次數 = \(n-1\)。

    Method IIStep 1: Find max of 1st half of S → Call this m1;
Step 2: Find max of 2nd half of S → Call this m2;
Step 3: Compare m1 and m2, return max of them;
/** Step 1 and Step 2 are done by recursion **/

    令 \(T(n)\) = 用此方法找 \(n\) 個數最大值的比較次數：

    \[T(1)=0,\qquad T(n)=T(\lfloor n/2\rfloor)+T(\lceil n/2\rceil)+1 \;\Rightarrow\; T(n)=n-1\]

    （由 substitution method 求得）

    💡
    下界：\(n-1\) 次 每個不是最大值的數都必須在某次比較中「輸」一次，而每次比較只會產生 1 個輸家 → 至少需要 \(n-1\) 次比較（連 best case 也是）。

    Algo-Lecture-08.pdf p.3–6

    2. 同時找最大值與最小值

    Method I：分別找

    先找 max，再找 min → 比較次數 \((n-1)+(n-1)\approx 2n\)。

    Method II：兩兩配對

    Method II（n 為偶數）1. Partition numbers into pairs
2. Compare numbers within a pair
3. Find max among larger numbers
4. Find min among smaller numbers

    比較次數 = \(n/2+(n/2-1)+(n/2-1)=1.5n-2\)。

    Method II（n 為奇數）1. Ignore S[n] for the moment
2. Find max M and min m in S[1..n–1]
3. Compare S[n] and M to get the true max
4. Compare S[n] and m to get the true min

    比較次數 = \(1.5(n-1)-2+2=1.5(n-1)\)。

    Algo-Lecture-08.pdf p.7–9

    3. 同時找 Max 與 Min 的下界

    Method II 已經是最好的：

    • \(n\) 為偶數：至少 \(1.5n-2\) 次比較
    • \(n\) 為奇數：至少 \(1.5(n-1)\) 次比較

    證明想法

    • 對任何演算法 ALG，構造一個「壞」輸入，逼 ALG 做很多次比較。
    • 一開始不設定數字的值；ALG 執行時，由我們決定每次比較的結果；ALG 停止時才把數值固定下來。

    把 \(n\) 個數想成 \(n\) 個選手，目標是找出最強和最弱的選手。每人一開始持有一顆紅球和一顆藍球：

    球意義
    🔴 紅球到目前為止沒輸過，仍可能是最強 (max)
    🔵 藍球到目前為止沒贏過，仍可能是最弱 (min)

    ALG 比較兩個選手時，依他們持有的球決定結果：

    1. 兩人都有兩顆球：其中一人贏，並保留紅球。
    2. 某人只有紅球：他贏，保留紅球。
    3. 某人只有藍球：他輸，保留藍球。
    4. 某人有兩顆球、另一人沒有球：有球的人贏，保留紅球。

    （另一位選手依結果移除對應的球。）兩人都沒有球時，選擇勝負時要避免勝負關係形成有向環 (directed cycle)；ALG 結束時勝負關係沒有有向環，就能用 topological sort 一致地指定數值（贏的人值較大）。

    計算

    • 正確的 ALG 結束時，只剩一顆紅球和一顆藍球 → 必須移除 \(2n-2\) 顆球。
    • 只有「兩人都有兩顆球」時一次比較能移除 2 顆球，最多發生 \(n/2\) 次（\(n\) 偶數）或 \((n-1)/2\) 次（\(n\) 奇數）；其他情況最多移除 1 顆。
    • \(n\) 偶數：\(n/2\) 次比較最多移除 \(n\) 顆，剩下的至少要 \(n-2\) 次 → 至少 \(1.5n-2\) 次。
    • \(n\) 奇數：\((n-1)/2\) 次比較最多移除 \(n-1\) 顆，剩下的至少要 \(n-1\) 次 → 至少 \(1.5(n-1)\) 次。

    Algo-Lecture-08.pdf p.10–23

    4. 找第 k 小的數 (Selecting kth Smallest)

    直接的方法：重複找 min、第 2 小、第 3 小…直到第 \(k\) 小 → \(O(kn)\) 次比較；\(k=O(1)\) 時好，\(k\) 大時差。能不能對任何 \(k\) 都做到 \(O(n)\)？

    Method I：用 Quicksort 的 partition

    Select Method I1. Pick a pivot p from S[1..n]
2. Partition S by p into S_small and S_large
3. Count the size of S_small → Call this z
4. if (z == k–1) return p
   if (z ≥ k)    Find kth smallest in S_small
   else          Find (k–z–1)th smallest in S_large
    • Worst case：\(T(n)=n+T(n-1)\Rightarrow T(n)=\Theta(n^2)\)
    • 隨機選 pivot：有很高的機率執行時間為 \(\Theta(n)\)；期望執行時間也是 \(\Theta(n)\)

    Method II：Median of Medians

    Method I 可能很慢，因為 pivot 可能把 \(S\) 分得很不平均。花一點額外時間找一個好的 pivot，使子問題大小最多為原本的 \(3/4\)，worst case 就能是 \(O(n)\)。

    1. 把 \(S\) 分成 \(\lceil n/5\rceil\) 組，每組 5 個數（可能有一組較少），各組分別排序並取出中位數。
    2. 取這些中位數的中位數 \(m\)（median of medians）。
    3. 至少 \(n/4\) 個數 \(\le m\)，也至少 \(n/4\) 個數 \(\ge m\)。
    4. 用 \(m\) 做 partition → \(|S_{small}|\le 3n/4\) 且 \(|S_{large}|\le 3n/4\)，所以 \(m\) 是好的 pivot。
    Select Method II1. Find median-of-medians m from S[1..n] as a pivot p
2. Partition S by p into S_small and S_large
3. Count the size of S_small → Call this z
4. if (z == k–1) return p
   if (z ≥ k)    Find kth smallest in S_small
   else          Find (k–z–1)th smallest in S_large

    Step 1 用遞迴找 median of medians。令 \(T'(n)\) 為此方法的執行時間，worst case：

    \[T'(n)=\underbrace{n+T'(n/5)}_{\text{Step 1}}+\underbrace{n}_{\text{Steps 2, 3}}+\underbrace{T'(3n/4)}_{\text{Step 4}} \;\Rightarrow\; T'(n)=\Theta(n)\]

    （由 recursion tree 求得）

    Algo-Lecture-08.pdf p.24–33

    自我測驗

    Q1. 為什麼找最大值至少需要 \(n-1\) 次比較？

    每個非最大值的數都必須在某次比較中輸一次，而每次比較只產生 1 個輸家。

    Algo-Lecture-08.pdf p.6

    Q2. \(n\) 為偶數時，同時找 max 和 min 最少需要幾次比較？用什麼方法達成？

    \(1.5n-2\) 次。兩兩配對比較，再在較大的數中找 max、較小的數中找 min。

    Algo-Lecture-08.pdf p.8, p.10

    Q3. 下界證明中，為什麼要移除 \(2n-2\) 顆球？

    一開始共 \(2n\) 顆球；正確的演算法結束時，只能剩下一顆紅球（max）和一顆藍球（min）。

    Algo-Lecture-08.pdf p.22

    Q4. 用 median of medians 當 pivot，partition 後兩邊最多多大？

    \(|S_{small}|\le 3n/4\) 且 \(|S_{large}|\le 3n/4\)。

    Algo-Lecture-08.pdf p.31

    Q5. Selection Method II 的遞迴式是什麼？解是多少？

    \(T'(n)=n+T'(n/5)+n+T'(3n/4)\)，\(T'(n)=\Theta(n)\)。

    Algo-Lecture-08.pdf p.33
