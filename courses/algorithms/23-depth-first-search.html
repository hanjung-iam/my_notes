    重點摘要

    • DFS：先把一條分支探索到底，再探索另一條分支；用遞迴（或 stack）實作，時間 \(O(|V|+|E|)\)。
    • White-Path Theorem：若 \(u\) 能經由一條全是 unvisited 頂點的路徑到達 \(v\)，則 DFS on \(u\) 會 discover 路徑上所有頂點。
    • 對所有 unvisited 頂點重複做 DFS → 得到 DFS forest。
    • Directed graph \(G\) 有 cycle ⇔ DFS 中存在 back edge → 可在線性時間偵測 cycle。
    • Parentheses Theorem：若 \(d(u)<d(v)\)，則兩個區間不是完全包含（\(d(u)<d(v)<f(v)<f(u)\)）就是完全不相交（\(d(u)<f(u)<d(v)<f(v)\)）。

    1. Depth-First Search

    另一個找出從 source \(s\) 可到達的所有頂點的簡單方法。想法：先把一條分支探索到越深越好，再探索另一條分支。

    DFSDFS(vertex u)
1. Mark u as discovered
2. for ( each neighbor v of u )
       if ( v is not finished and not discovered )
           DFS( v );
   Mark u as finished;

To find all vertices reachable from s, run DFS(s)

    當 \(s\) 被 finished 時結束；discover 新節點時的邊方向形成一棵樹，包含所有從 \(s\) 可到達的節點 → 稱為 \(s\) 的 DFS tree。

    Algo-Lecture-23_241211_152224.pdf p.3–10

    2. White-Path Theorem

    💡
    White-Path Theorem 若 \(u\) 能經由某條路徑 \(P\) 到達 \(v\)，且 \(P\) 上都是 unvisited 頂點（not discovered and not finished），則 \(P\) 上所有頂點都會被 DFS on \(u\) discover。

    證明（反證法）

    1. 令 \(P=(v_0,v_1,\dots,v_k)\)，\(v_0=u\)、\(v_k=v\)；\(v_0=u\) 一定被 DFS on \(u\) discover。
    2. 假設 \(P\) 上有頂點沒被 discover → 存在某個 \(v_j\) 被 discover，但 \(v_{j+1}\) 沒有。
    3. 因為 \(v_j\) 被 discover，它的所有鄰居都會在 \(v_j\) finished 之前被 discover → 矛盾（講義留作思考：why?）。

    手寫筆記對矛盾的說明：\(v_k\) 應該要在 \(P\) 上其他所有頂點 finished 之前先 finished。

    Algo-Lecture-23_241211_152224.pdf p.11–12；手寫筆記_White_path_thm.pdf p.1

    DFS 的正確性

    • 一開始所有頂點都是 unvisited → 若 \(v\) 可從 \(s\) 到達，就有一條從 \(s\) 到 \(v\) 的 unvisited 路徑 → 由 White-Path Theorem，\(v\) 會被 DFS on \(s\) discover。
    • 另外，每個被 discover 的頂點都可從 \(s\) 到達（講義留作思考：why?）。
    • → \(v\) 被 DFS on \(s\) discover ⇔ \(s\) 能到達 \(v\)。

    Algo-Lecture-23_241211_152224.pdf p.13

    3. 實作與 Connected Components

    • 用 \(O(|V|)\) 大小的陣列記錄每個頂點的 discovered／finished 狀態。
    • 可以用遞迴實作，也可以用 stack（講義留作思考：how?）。
    • 每個頂點最多被 discover 一次、每條邊最多被看兩次 → \(O(|V|+|E|)\)。
    Finding Connected Componentsfor ( each vertex u )
    if ( u is not visited )
        Run DFS with u as source;

    每跑一次 DFS 就找到一個新的 component，時間與該 component 的邊數成正比 → 總共 \(O(|V|+|E|)\)。

    Algo-Lecture-23_241211_152224.pdf p.14–15

    4. DFS Forest (Lecture 23S)

    • 設 \(G\) 是 directed graph。對任何 unvisited 頂點重複做 DFS，直到所有頂點都被 visit。
    • 每做一次新的 DFS，就得到一棵新的 DFS tree → 這些 rooted trees 形成 DFS forest。
    • 講義例子依序在 s、t、y、r、v 上做 DFS。

    Algo-Lecture-23S_241211_161801.pdf p.3–9

    5. 偵測 Cycle

    💡
    Theorem 對 directed graph \(G\) 做 DFS：\(G\) 有 cycle ⇔ 存在 back edge。
    → 可以在線性時間內偵測 \(G\) 是否有 cycle。

    證明

    (⇒) 假設 \(G\) 有 cycle \(C\)：

    • 令 \(v\) 是 \(C\) 中 discovery time 最早的頂點，\(u\) 是 \(C\) 中 \(v\) 的前一個頂點。
    • 由 White-Path Theorem，\(u\) 會被 DFS on \(v\) discover → \(v\) 是 \(u\) 在 DFS tree 中的 ancestor → \((u,v)\) 是 back edge。

    (⇐) 假設有 back edge \((u,v)\)：

    • \(v\) 是 \(u\) 在 DFS tree 中的 ancestor → \(G\) 中有一條從 \(v\) 到 \(u\) 的有向路徑 \(P\)。
    • \(P\) 加上邊 \((u,v)\) 形成 cycle。

    Algo-Lecture-23S_241211_161801.pdf p.10–12；手寫筆記_White_path_thm.pdf p.1–2

    6. Discovery／Finishing Time 與 Parentheses Theorem

    DFS 時記錄頂點 discovery time 與 finishing time 的相對順序：\(d(v)\) = \(v\) 的 discovery time，\(f(v)\) = \(v\) 的 finishing time。

    假設 \(d(u)<d(v)\)，分兩種情況：

    情況推理結果
    Case 1：\(u\) 被 discover 時，\(u\) 能經由 unvisited 頂點到達 \(v\)由 White-Path Theorem，\(v\) 在 DFS on \(u\) 期間被 discover → \(v\) 在 \(u\) finished 前就 finished\(f(v)<f(u)\)
    Case 2：\(u\) 無法經由 unvisited 頂點到達 \(v\)DFS on \(u\) 期間 \(v\) 不會被 discover → \(u\) 在 \(v\) 被 discover 前就 finished\(f(u)<d(v)\)
    💡
    Parentheses Theorem 若 \(d(u)<d(v)\)，則必為下列其中之一：
    1. \(d(u)<d(v)<f(v)<f(u)\)　[完全包含]
    2. \(d(u)<f(u)<d(v)<f(v)\)　[完全不相交]

    Algo-Lecture-23S_241211_161801.pdf p.13–16；手寫筆記_White_path_thm.pdf p.2

    自我測驗

    Q1. 寫出 DFS 的 pseudocode。

    DFS(u)：mark u as discovered；對每個鄰居 v，若 v 不是 finished 也不是 discovered，就 DFS(v)；最後 mark u as finished。

    Algo-Lecture-23_241211_152224.pdf p.4

    Q2. 敘述 White-Path Theorem。

    若 \(u\) 能經由一條全是 unvisited 頂點的路徑 \(P\) 到達 \(v\)，則 \(P\) 上所有頂點都會被 DFS on \(u\) discover。

    Algo-Lecture-23_241211_152224.pdf p.11

    Q3. 如何用 DFS 判斷 directed graph 是否有 cycle？

    做 DFS 並檢查是否有 back edge：\(G\) 有 cycle ⇔ 存在 back edge，可在線性時間完成。

    Algo-Lecture-23S_241211_161801.pdf p.10

    Q4. 證明「有 cycle ⇒ 有 back edge」時，\(v\) 怎麼選？

    選 cycle 中 discovery time 最早的頂點 \(v\)，令 \(u\) 為 cycle 中 \(v\) 的前一個頂點；由 White-Path Theorem，\(u\) 被 DFS on \(v\) discover，所以 \((u,v)\) 是 back edge。

    Algo-Lecture-23S_241211_161801.pdf p.11

    Q5. 若 \(d(u)<d(v)\)，Parentheses Theorem 說哪兩種情況之一必成立？

    \(d(u)<d(v)<f(v)<f(u)\)（完全包含）或 \(d(u)<f(u)<d(v)<f(v)\)（完全不相交）。

    Algo-Lecture-23S_241211_161801.pdf p.16
