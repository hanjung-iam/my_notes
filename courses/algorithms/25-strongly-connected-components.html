    重點摘要

    • \(u\leftrightarrow v\)（mutually reachable）是 equivalence relation → 把頂點分組，每組的 induced subgraph 是一個 SCC。
    • 把每條邊反向得到 \(H\)：\(G\) 與 \(H\) 的 SCC 相同。
    • 把每個 SCC 縮成一點得到 component graph，它一定是 acyclic。
    • 演算法：在 \(G\) 上做 DFS → 依 finishing time 由晚到早挑未拜訪的頂點，在反向圖 \(H\) 上做 BFS，每次找到一個 SCC → \(O(|V|+|E|)\)。
    • 關鍵：DFS 中最後 finished 的頂點，所在的 SCC 在 \(G\) 的 component graph 中 in-degree 為 0（在 \(H\) 中 out-degree 為 0）。

    1. 定義

    • 設 \(G\) 是 directed graph。若 \(u\) 能到達 \(v\)，且 \(v\) 也能到達 \(u\)，則兩者 mutually reachable，記為 \(u\leftrightarrow v\)；假設對每個頂點 \(u\)，\(u\leftrightarrow u\)。
    • \(\leftrightarrow\) 是 equivalence relation → 可以用它把頂點分組：\(u\)、\(v\) 在同一組 ⇔ \(u\leftrightarrow v\)。
    • 每一組的 induced subgraph 稱為一個 Strongly Connected Component (SCC)。

    Algo-Lecture-25_241211_145203.pdf p.3–5；手寫筆記_White_path_thm.pdf p.5

    2. SCC 的性質

    反向圖

    把 \(G\) 的每條邊反向，得到 \(H\)（頂點相同）。則 \(u\leftrightarrow v\) in \(G\) ⇔ \(u\leftrightarrow v\) in \(H\) → \(G\) 的每個 SCC 在 \(H\) 中都有對應的 SCC（同一組頂點）。

    Algo-Lecture-25_241211_145203.pdf p.6

    Component Graph

    把 \(G\) 的每個 SCC 縮成一個頂點，並移除 loop、把多重邊變成單一邊，得到的 simple graph 稱為 \(G\) 的 component graph。

    💡
    性質 \(G\) 的 component graph 是 acyclic。
    證明：假設有 cycle，則 component graph 中存在 \(v_j\leftrightarrow v_k\) → 它們對應的 SCC \(V_j\)、\(V_k\) 的頂點彼此可達 → 應該是同一個 SCC，矛盾。
    📝
    例子（講義與手寫筆記） 圖中的頂點 r, s, t, u, v, w, x, y 被分成三個 SCC，縮點後的 component graph 為 \(v_1\to v_2\to v_3\)。

    Algo-Lecture-25_241211_145203.pdf p.9–10；手寫筆記_White_path_thm.pdf p.5

    在 \(H\) 上做 BFS

    • 若在 \(H\) 上以 \(x\) 為 source 做 BFS，而 \(x\) 所在的 SCC 在 \(H\) 的 component graph 中 out-degree 為 0，則 BFS 會剛好拜訪和 \(x\) 同一個 SCC 的頂點。

    Algo-Lecture-25_241211_145203.pdf p.11–13

    3. 找出所有 SCC

    策略

    Basic strategy1. while ( H contains unvisited vertex ) {
2.     Pick a vertex x;
3.     Find all vertices in the same SCC as x;
4.     Visit all vertices found in Line 3;
5. }

    找 \(G\) 的所有 SCC 等於找 \(H\) 的所有 SCC。為了有效率，要小心選 \(x\)：

    Refined strategy1. while ( H contains unvisited vertex ) {
2.     Pick an unvisited vertex x inside an SCC, whose
       corresponding vertex in component graph of H
       has out-degree 0;
3.     Run BFS, with source x, in H;
4. }

    怎麼找到這樣的 \(x\)？

    💡
    Claim 在原圖 \(G\) 上做 DFS，finishing time 最晚的頂點 \(u\) 就是一個合格的 \(x\)：\(u\) 所在的 SCC 在「\(H\) 的 component graph」中 out-degree 為 0；等價地，在「\(G\) 的 component graph」中 in-degree 為 0。

    Algo-Lecture-25_241211_145203.pdf p.7–8, p.14–15；手寫筆記_White_path_thm.pdf p.5

    最終演算法

    Finding SCCs1. Run DFS on G; Get reverse graph H of G;
2. Set all vertices as unvisited;
3. while ( H contains unvisited vertex ) {
4.     Pick an unvisited vertex u with latest finishing time;
5.     Run BFS, with source u, in H;
6. } /* Total Time: O(|V|+|E|) */

    也可以交換 \(G\) 與 \(H\) 的角色：

    Finding SCCs（交換 G、H）1. Get reverse graph H of G; Run DFS on H;
2. Set all vertices as unvisited;
3. while ( G contains unvisited vertex ) {
4.     Pick an unvisited vertex u with latest finishing time;
5.     Run BFS, with source u, in G;
6. } /* Total Time: O(|V|+|E|) */

    Algo-Lecture-25_241211_145203.pdf p.16–17；手寫筆記_White_path_thm.pdf p.5

    4. Claim 的正確性

    💡
    Theorem 在 \(G\) 上做 DFS，若 \(G\) 的 component graph 中有邊 \((w,v)\)，則 DFS 最後 finished 的頂點不可能在 \(v\) 的 SCC 中。

    證明：

    • 令 \(x\) = SCC(\(w\)) 中第一個被 DFS discover 的頂點；\(y\) = SCC(\(v\)) 中第一個被 discover 的頂點；\(z\) = SCC(\(v\)) 中最後 finished 的頂點（\(z\) 可能等於 \(y\)）。
    • 由 White-Path Theorem：\(d(y)\le d(z)<f(z)\le f(y)\)。
    • Case 1：\(d(x)<d(y)\) → 由 White-Path，\(d(x)<d(z)<f(z)<f(x)\)。
    • Case 2：\(d(y)<d(x)\) → SCC(\(v\)) 的所有頂點在 \(x\) 開始前就拜訪完 → \(f(z)<d(x)<f(x)\)。
    • 兩種情況 SCC(\(w\)) 中都有頂點比 \(z\) 晚 finished → 最後 finished 的頂點不會是 \(z\)，也就不會在 SCC(\(v\)) 中。

    因此最後 finished 的頂點所在的 SCC 沒有 incoming edge（in-degree 0），Claim 成立。

    Algo-Lecture-25_241211_145203.pdf p.18–20

    自我測驗

    Q1. 什麼是 SCC？

    用 mutually reachable 關係 \(\leftrightarrow\)（equivalence relation）把頂點分組，每一組的 induced subgraph 就是一個 SCC。

    Algo-Lecture-25_241211_145203.pdf p.3–4

    Q2. 為什麼 component graph 一定是 acyclic？

    若有 cycle，cycle 上兩個 SCC 的頂點彼此可達，應該屬於同一個 SCC，矛盾。

    Algo-Lecture-25_241211_145203.pdf p.10

    Q3. 寫出找所有 SCC 的演算法。

    在 \(G\) 上做 DFS 並取得反向圖 \(H\)；把所有頂點設為 unvisited；當 \(H\) 還有未拜訪的頂點，挑 finishing time 最晚的未拜訪頂點 \(u\)，在 \(H\) 上以 \(u\) 為 source 做 BFS。總時間 \(O(|V|+|E|)\)。

    Algo-Lecture-25_241211_145203.pdf p.16

    Q4. DFS 中最後 finished 的頂點 \(u\) 有什麼性質？

    \(u\) 所在的 SCC 在 \(G\) 的 component graph 中 in-degree 為 0，等價於在 \(H\) 的 component graph 中 out-degree 為 0。

    Algo-Lecture-25_241211_145203.pdf p.15

    Q5. 證明 Claim 時，Case 2（\(d(y)<d(x)\)）為什麼得到 \(f(z)<d(x)\)？

    因為 SCC(\(v\)) 的所有頂點在 \(x\) 開始被 DFS 前就已經拜訪完（\(v\) 無法回到 \(w\) 的 SCC）。

    Algo-Lecture-25_241211_145203.pdf p.20
