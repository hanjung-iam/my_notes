    重點摘要

    • Topological Sort：排列頂點，使每條邊 \((u,v)\) 中 \(u\) 都排在 \(v\) 前面。
    • 有 directed cycle 就不能做 topological sort；DAG 一定可以。
    • Key Lemma：DAG 一定有 in-degree 為 0 的頂點。
    • Method I：反覆輸出 in-degree 0 的頂點；用 in-degree 陣列 \(A\) 與 list \(L\) 實作 → \(O(|V|+|E|)\)。
    • Method II：做 DFS，依 finishing time 遞減輸出；用 stack 免排序 → \(O(|V|+|E|)\)。

    1. Topological Sort 問題

    • Directed graph 可以表示一組事件之間的先後順序 (precedence)，例如穿衣服：under-shorts → pants → belt…
    • 設 \(G\) 是這樣的 precedence graph。能不能把頂點排成一列，使得只要 \((u,v)\) 是 \(G\) 的邊，\(u\) 就出現在 \(v\) 之前？這就是 Topological Sort 問題。
    • 若 \(G\) 有 directed cycle，就無法 topological sort（可用反證法證明）。
    • 但若 \(G\) 是 acyclic，topological sort 一定做得到。

    Algo-Lecture-24_241212_135033.pdf p.3–6

    2. Key Lemma

    💡
    Key Lemma 設 \(G\) 是 directed acyclic graph（DAG，手寫筆記：沒有 cycle 的圖），則 \(G\) 中一定有某個頂點的 in-degree 為 0。

    證明

    1. 從任意頂點 \(v_0\) 開始。若 \(v_0\) 的 in-degree 為 0 → 完成。否則存在某個 \(v_1\) 指向 \(v_0\)。
    2. 若 \(v_1\) 的 in-degree 為 0 → 完成。否則存在某個 \(v_2\) 指向 \(v_1\)…
    3. 持續下去，要嘛找到 in-degree 為 0 的頂點，要嘛得到 \(v_k\to v_{k-1}\to\dots\to v_1\to v_0\)。
    4. 這些頂點一定都不同；否則（例如 \(v_1=v_k\)）就形成 directed cycle，和 \(G\) 是 DAG 矛盾。
    5. 但 \(G\) 的頂點數有限 → 過程一定會停 → 找到 in-degree 為 0 的頂點。

    Algo-Lecture-24_241212_135033.pdf p.7–11；手寫筆記_White_path_thm.pdf p.3

    3. Method I：反覆輸出 In-degree 0 的頂點

    為什麼 DAG 一定可以

    Pseudocode1. Find a vertex u with in-degree 0
2. Output u
3. Remove u and its outgoing edges from G
4. Repeat Steps 1 ~ 3 to output the next vertex

    移除後的圖仍然是 DAG；輸出的頂點形成 topological sort 順序（講義留作思考：why?）。

    直接照做：每一輪花 \(O(|V|+|E|)\) 計算每個頂點的 in-degree，共 \(O(|V|)\) 輪 → 總時間 \(O(|V|(|V|+|E|))\)。可以做得更好。

    Algo-Lecture-24_241212_135033.pdf p.12–13；手寫筆記_White_path_thm.pdf p.3

    改良版

    Pseudocode1. Keep an O(|V|)-size array A for in-degree of each vertex
2. Initialize a list L of vertices whose in-degree is 0
3. while ( L is not empty )
       Pick a vertex u from L and output u
       for ( each out-neighbor v of u )
           Decrement A[v] by 1;
           if ( A[v] becomes 0 ) Add u to L;
    ⚠️
    待確認 講義 p.14 最後一行寫「if ( A[v] becomes 0 ) Add u to L」，但前面遞減的是 A[v]；手寫筆記 p.4 的寫法是「for (each out-neighbor u of v) A[u]--；if (A[u]==0) Add u to L」，變數名稱一致。上方 pseudocode 依講義原文照錄，請對照確認。
    • Line 1、Line 2 可以藉由處理輸入的 adjacency lists 完成。
    • Line 3 的迴圈反覆移除並輸出 in-degree 為 0 的頂點 \(u\)；移除 \(u\) 時也移除所有邊 \((u,v)\)，所以要更新陣列 \(A\)。
    • 若 \(v\) 沒有 incoming edge，\(v\) 隨時都可以輸出。

    時間：Line 1、2 花 \(O(|V|+|E|)\)；Line 3 中每個頂點最多加入 \(L\) 一次、每條邊最多處理一次 → \(O(|V|+|E|)\)。總共 \(O(|V|+|E|)\)。

    ⚠️
    待確認 手寫筆記 p.4 寫「Line 1 and Line 2 takes \(O(|V|)\)」，講義 p.16 寫 Line 1、Line 2 花 \(O(|V|+|E|)\)。兩者的總時間都是 \(O(|V|+|E|)\)。

    Algo-Lecture-24_241212_135033.pdf p.14–16；手寫筆記_White_path_thm.pdf p.4

    4. Method II：用 DFS

    Pseudocode（手寫筆記整理）1. Traverse G by DFS and record the finishing time for each vertex
2. Output vertices in descending order of finishing time
    📝
    例子 穿衣服的圖做一次 DFS 後，依 finishing time 遞減由左到右排列這些事件 → 所有邊的方向都由左指向右。

    為什麼正確

    首先 \(G\) 必須是 DAG。由 White-Path Theorem，對每條邊 \((u,v)\)：

    • 若 \(d(u)<d(v)\)，則 \(d(u)<d(v)<f(v)<f(u)\)；
    • 若 \(d(v)<d(u)\)，則 \(d(v)<f(v)<d(u)<f(u)\)。

    → 不論哪種情況，\(f(v)<f(u)\)，所以依 finishing time 遞減輸出時 \(u\) 在 \(v\) 前面。

    時間

    • DFS 花 \(O(|V|+|E|)\)。
    • 排序 finishing times：直接排序 \(O(|V|\log|V|)\)；較聰明的方法是用一個額外的 stack \(S\)，頂點一 finished 就 push 進 \(S\) → 不需要排序。
    • 總時間 \(O(|V|+|E|)\)（手寫筆記：Run DFS \(O(|V|+|E|)\) + Output \(O(|V|)\)）。

    Algo-Lecture-24_241212_135033.pdf p.17–19；手寫筆記_White_path_thm.pdf p.4

    自我測驗

    Q1. 什麼樣的圖無法做 topological sort？

    有 directed cycle 的圖。若 \(G\) 是 acyclic（DAG），topological sort 一定做得到。

    Algo-Lecture-24_241212_135033.pdf p.6

    Q2. 證明 DAG 一定有 in-degree 為 0 的頂點。

    從任意頂點往回找指向它的頂點；這些頂點一定不同（否則形成 cycle），而頂點數有限，所以過程一定會停在 in-degree 為 0 的頂點。

    Algo-Lecture-24_241212_135033.pdf p.7–11

    Q3. 直接反覆「找 in-degree 0 頂點 → 輸出 → 移除」的時間是多少？怎麼改良？

    每輪 \(O(|V|+|E|)\)、共 \(O(|V|)\) 輪 → \(O(|V|(|V|+|E|))\)。改良：用陣列 \(A\) 記 in-degree、用 list \(L\) 存 in-degree 為 0 的頂點，總時間 \(O(|V|+|E|)\)。

    Algo-Lecture-24_241212_135033.pdf p.13–16

    Q4. 為什麼依 DFS finishing time 遞減輸出就是 topological order？

    在 DAG 上，對每條邊 \((u,v)\)，不論 \(d(u)<d(v)\) 或 \(d(v)<d(u)\)，都有 \(f(v)<f(u)\)。

    Algo-Lecture-24_241212_135033.pdf p.18

    Q5. Method II 如何避免排序 finishing times？

    用一個額外的 stack，頂點一 finished 就 push 進去，總時間 \(O(|V|+|E|)\)。

    Algo-Lecture-24_241212_135033.pdf p.19
