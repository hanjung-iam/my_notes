    堆積 排序

    重點摘要

    • Heap（binary heap）= 滿足 shape property 與 heap property（節點值 ≤ 子節點值）的 binary tree → root 永遠是最小值。
    • 高度 \(h\) 滿足 \(2^{h-1}-1<n\le 2^h-1\) → \(h=\Theta(\log n)\)。
    • Find-Min \(O(1)\)；Insert、Extract-Min 都是 \(O(\log n)\)（每次 swap 移動一層）。
    • Heapsort 的另一種建 heap 方式：把數字直接放進節點，再由下往上逐層 Heapify → 建 heap 只要 \(4n=O(n)\)，但排序總時間仍是 \(O(n\log n)\)。
    • 用陣列存 heap：節點 \(x\) 的 parent \(\lfloor x/2\rfloor\)、left \(2x\)、right \(2x+1\)，不需要 pointer。

    1. 什麼是 Heap

    Heap（或 binary heap）是滿足下列兩個性質的 binary tree：

    1. Shape Property：除了最深的一層，每一層都填滿；最深的一層由左到右填。
    2. Heap Property：節點的值 ≤ 子節點的值。
    • 節點數相同的 heap，形狀都一樣。
    • 滿足 heap property → root 永遠是最小值。

    Algo-Lecture-04_240917_221048.pdf p.3–5；手寫筆記_Sorting_DP.pdf p.10

    Heap 的高度

    令 \(h\) = 有 \(n\) 個節點的 heap 的 node height。上面 \(h-1\) 層全滿、\(h\) 層最多全滿：

    \[2^{h-1}-1<n\le 2^h-1\quad\Rightarrow\quad h=\Theta(\log n)\]

    手寫筆記的推導：\(1+2+4+\dots+2^{h-2}<n\le 1+2+4+\dots+2^{h-1}\)，用等比級數 \(\frac{1\cdot(2^{h-1}-1)}{2-1}<n\le\frac{1\cdot(2^h-1)}{2-1}\) 得到上式。

    Algo-Lecture-04_240917_221048.pdf p.6；手寫筆記_Sorting_DP.pdf p.10

    2. Heap 的操作

    Heap 維護一個動態數字集合 \(S\)，支援三種操作：

    操作作用做法時間
    Find-Min回傳 \(S\) 的最小值最小值永遠在 root\(O(1)\)
    Insert加入新數字新增節點修正形狀 → 放入新值 → 修正 heap property\(O(\log n)\)
    Extract-Min移除最小值最後一個節點的值複製到 root → 移除最後節點 → 修正 heap property\(O(\log n)\)

    Algo-Lecture-04_240917_221048.pdf p.7–8；手寫筆記_Sorting_DP.pdf p.10

    Insert

    1. Restore Shape Property：建立一個含新值的節點，加到 heap 的正確位置。
    2. Restore Heap Property：標記新節點，只有它的 parent 可能違反 heap property；若違反就和 parent 交換，交換後只有它新的 parent 可能違反；直到滿足為止。
    📝
    例子：插入 5 原 heap（逐層）：3 ／ 8, 4 ／ 13, 23, 12, 24 ／ 43, 38。5 先接在 23 下面 → 5 < 23 交換 → 5 < 8 交換 → 5 > 3 停止。結果：3 ／ 5, 4 ／ 13, 8, 12, 24 ／ 43, 38, 23。

    每次交換，新值往上移一層 → \(O(\log n)\) 次交換，每次 \(O(1)\) → Insert 為 \(O(\log n)\)。

    Algo-Lecture-04_240917_221048.pdf p.9–13

    Extract-Min

    1. 把最後一個節點的內容複製到 root。
    2. 移除最後一個節點，修正形狀。
    3. 標記 root，只有它可能違反 heap property；若違反就和較小的 child 交換，直到滿足為止。
    📝
    例子 同一個 heap 做 Extract-Min：最後節點 38 複製到 root → 38 和較小的 child 4 交換 → 再和較小的 child 12 交換 → 停止。結果：4 ／ 8, 12 ／ 13, 23, 38, 24 ／ 43。

    每次交換往下移一層 → Extract-Min 為 \(O(\log n)\)。

    Algo-Lecture-04_240917_221048.pdf p.14–18

    3. Heapsort

    用 Heap 排序

    1. 把 \(n\) 個數字一個一個 Insert 進 heap；
    2. 一個一個 Extract-Min。

    兩步都是 \(O(n\log n)\) → 總時間 \(O(n\log n)\)。

    ⚠️
    待確認 手寫筆記 p.11 在「Insert the numbers one by one to a heap」旁寫 \(O(n)\)；講義 p.19 寫兩個步驟（逐一 Insert、逐一 Extract-Min）都是 \(O(n\log n)\)。請對照確認。

    Algo-Lecture-04_240917_221048.pdf p.19；手寫筆記_Sorting_DP.pdf p.11

    另一種建 Heap 的方式：Heapify

    💡
    Lemma 若 binary tree \(T\) 的 root 的兩個子樹 \(L\)、\(R\) 都是 heap，則可以在 \(O(\text{height}(T))\) 時間內讓 \(T\) 滿足 heap property。

    證明（這個操作記為 Heapify(u)）：和 Extract-Min 修正 heap property 的方法一樣 — 比較 root \(r\) 與 \(L\)、\(R\) 的 root \(r_L\)、\(r_R\)；若違反 heap property，就把 \(r\) 和 \(r_L\)、\(r_R\) 中較小的交換，再遞迴修正。每一步 \(r\) 往下一層 → 時間 \(O(\text{height}(T))\)（講義寫為 \(2\cdot\max\{\text{height}(L),\text{height}(R)\}\)）。

    Alternative Step 1：

    1. 先把 \(n\) 個數字放進 heap 的節點，不管 heap property。
    2. 由最底層往上逐層處理每個節點（用上面的 lemma）→ 處理完節點 \(x\) 後，以 \(x\) 為 root 的子樹變成 heap。

    用這種方式得到的排序演算法稱為 Heapsort；建 heap 比較快，但總時間仍是 \(O(n\log n)\)。

    📝
    例子（講義與手寫筆記） 初始：12 ／ 4, 13 ／ 43, 23, 8, 3 ／ 24, 38。由下往上 heapify：以 43 為 root 的子樹 → 24 上移（4 ／ 24, 23 ／ 43, 38）；以 13 為 root 的子樹 → 3 上移；最後 heapify 整棵樹 → 結果：3 ／ 4, 8 ／ 24, 23, 12, 13 ／ 43, 38。

    Algo-Lecture-04_240917_221048.pdf p.20–28；手寫筆記_Sorting_DP.pdf p.11

    Alternative Step 1 的時間

    由下往上標層數（最底層 = Level 1）：Level 1 最多 \(n\) 個節點、Level 2 最多 \(n/2\)、Level 3 最多 \(n/4\)…；Level \(k\) 的節點最多往下比較 \(k\) 次（手寫筆記：「最多向下比較的次數」）。

    \[\text{Total time}\le n\cdot 1+\frac{n}{2}\cdot 2+\frac{n}{4}\cdot 3+\frac{n}{8}\cdot 4+\dots=n\left(1+2\left(\tfrac12\right)+3\left(\tfrac12\right)^2+4\left(\tfrac12\right)^3+\dots\right)=4n\]

    因為 \(1+x+x^2+\dots=(1-x)^{-1}\)，微分得 \(1+2x+3x^2+\dots=(1-x)^{-2}\)，代入 \(x=\frac12\) 得 4。

    ⚠️
    待確認 手寫筆記 p.11 的級數第三項寫成「\(3(\frac{n}{4})\)」，講義 p.29 為 \(3(\frac12)^2\)。上方依講義寫法整理。

    Algo-Lecture-04_240917_221048.pdf p.29；手寫筆記_Sorting_DP.pdf p.11

    4. 用陣列表示 Heap

    • 把節點逐層、每層由左到右編號（root = 1）→ \(n\) 個節點的 heap 剛好用到編號 \(1,2,\dots,n\) → 可以存在陣列裡。

    自我測驗

    Q1. Heap 必須滿足哪兩個性質？

    Shape property：除最深層外每層都填滿，最深層由左到右填。Heap property：節點值 ≤ 子節點值。

    Algo-Lecture-04_240917_221048.pdf p.3

    Q2. Extract-Min 修正 heap property 時，要和哪個 child 交換？為什麼時間是 \(O(\log n)\)？

    和較小的 child 交換。每次交換往下一層，heap 高度為 \(\Theta(\log n)\)，所以最多 \(O(\log n)\) 次交換，每次 \(O(1)\)。

    Algo-Lecture-04_240917_221048.pdf p.16, p.18

    Q3. 用 Heapify 由下往上建 heap，總時間為什麼是 \(O(n)\)？

    Level \(k\)（由下往上數）最多 \(n/2^{k-1}\) 個節點，每個最多花 \(k\) 步；總和 \(n(1+2\cdot\frac12+3\cdot\frac14+\dots)=4n\)。

    Algo-Lecture-04_240917_221048.pdf p.29

    Q4. 陣列中 index 為 \(x\) 的節點，它的 parent、left child、right child 的 index 是多少？

    parent \(\lfloor x/2\rfloor\)、left child \(2x\)、right child \(2x+1\)。

    Algo-Lecture-04_240917_221048.pdf p.33

    Q5. \(n\) 個節點的 heap，高度 \(h\) 滿足什麼不等式？

    \(2^{h-1}-1<n\le 2^h-1\)，所以 \(h=\Theta(\log n)\)。

    Algo-Lecture-04_240917_221048.pdf p.6
