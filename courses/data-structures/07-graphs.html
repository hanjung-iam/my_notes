    圖論 最短路徑

    重點摘要

    • \(n\) 個頂點的圖最多 \(n(n-1)/2\)（無向）或 \(n(n-1)\)（有向）條邊；表示法有 adjacency matrix 與 adjacency lists。
    • DFS 用 stack（或遞迴）、BFS 用 queue；用 adjacency lists 時為 \(O(n+e)\)，用 adjacency matrix 時為 \(O(n^2)\)。
    • 最小生成樹 (MST) 的三個 greedy 演算法：Kruskal \(O(e\log e)\)、Prim \(O(n^2)\)、Sollin。
    • 最短路徑：單一起點用 Dijkstra（邊權非負）；所有點對用 Floyd-Warshall（DP，\(A^k[i][j]=\min\{A^{k-1}[i][j],A^{k-1}[i][k]+A^{k-1}[k][j]\}\)）。
    • AOV network 用 topological order 排出活動順序：反覆挑出沒有 predecessor（in-degree 為 0）的頂點。

    1. 圖的基本概念

    最早的記錄是 1736 年的 Königsberg 七橋問題（每座橋恰好走一次），由 Euler 解決：把問題表示成圖，可以走完 iff 每個頂點的 degree 都是偶數。

    • Graph \(G=(V,E)\)：\(V\) 為頂點集合、\(E\) 為邊集合。
    • Undirected graph：邊 \((u,v)\) 沒有方向。
    • Directed graph：\(\langle u,v\rangle\ne\langle v,u\rangle\)；\(\langle u,v\rangle\) 中 \(u\) 是 tail、\(v\) 是 head。
    • 限制：不允許 self edge / self loop（\((v,v)\)、\(\langle v,v\rangle\)）；同一條邊不能出現多次（那是 multigraph）。
    術語定義
    最多邊數無向：\(n(n-1)/2\)；有向：\(n(n-1)\)
    Complete graph恰好有上述最多邊數的圖
    Adjacent / Incident\((u,v)\in E\) 時 \(u\)、\(v\) 相鄰，邊 \((u,v)\) incident on \(u\) 和 \(v\)；\(\langle u,v\rangle\) 時 \(u\) is adjacent to \(v\)、\(v\) is adjacent from \(u\)
    Subgraph\(V(G')\subseteq V(G)\) 且 \(E(G')\subseteq E(G)\)
    Path頂點序列 \(u,i_1,\dots,i_k,v\)，相鄰兩點之間都有邊
    Simple path所有頂點都不同的 path（第一個和最後一個可以相同）
    Cycle第一個與最後一個頂點相同的 simple path
    Connected無向圖中每一對相異頂點之間都有 path
    Connected component極大的 connected subgraph
    Treeconnected 且 acyclic 的圖
    Strongly connected有向圖中每一對相異頂點之間都有 directed path
    Strongly connected component極大的 strongly connected subgraph
    Degree無向圖：節點連到的邊數。有向圖：in-degree（指進來的邊數）+ out-degree（指出去的邊數）

    2. 圖的表示法

    表示法做法特性
    Adjacency matrix二維陣列，\(a[i][j]=1\) iff 邊 \((i,j)\) 或 \(\langle i,j\rangle\) 在 \(E(G)\)圖很稀疏時浪費記憶體
    Adjacency lists每個頂點用一條 chain 串起它的相鄰頂點有向圖中 list 長度 = out-degree
    Inverse adjacency lists有向圖中，每個頂點串起 adjacent from 的頂點list 長度 = in-degree
    • Weighted edges：邊可以帶權重（例如距離、成本），在每條邊多加一個欄位存權重；有權重的圖稱為 network。
    • Graph ADT 以抽象 class 定義 Degree、ExistsEdge、InsertVertex、InsertEdge、DeleteVertex、DeleteEdge 等純虛擬函式；LinkedGraph 以 Chain<int> *adjLists 實作。操作與表示法無關，用 iterator 走訪相鄰頂點。

    3. DFS 與 BFS

    Depth-First Search (DFS)

    • 從頂點 \(v\) 開始：拜訪 \(v\)；對每個與 \(v\) 相鄰且未拜訪的 \(w\)，遞迴 DFS(\(w\))。
    • 若到達某頂點 \(u\)，其相鄰頂點都已拜訪，就退回上一個拜訪的頂點。
    • 當已拜訪的頂點都無法再到達未拜訪的頂點時結束。
    Recursive DFS（C++）void Graph::DFS(const int v){
    // visit all previously unvisited vertices that are adjacent to v
    output(v);
    visited[v]=true;
    for(each vertex w adjacent to v)
        if(!visited[w]) DFS(w);
}

    非遞迴版本改用 stack：pop 出頂點，若未拜訪就輸出、標記，並把所有未拜訪的相鄰頂點 push 進 stack。講義範例的一種 DFS 順序為 0 1 3 7 4 5 2 6（還有其他可能）。

    Breadth-First Search (BFS)

    從頂點 \(v\) 開始：拜訪 \(v\)，再拜訪所有與 \(v\) 相鄰的未拜訪頂點，接著拜訪與這些新頂點相鄰的未拜訪頂點…（生活例子：網路廣播、社群網路中先認識朋友的朋友）

    BFS（C++）void Graph::BFS(int v){
    visited = new bool[n]; // this is a data member of Graph
    fill(visited, visited+n, false);
    Queue<int> q;          // declare and init a queue
    q.Push(v);
    visited[v]=true;
    while(!q.IsEmpty()){
        v = q.Front(); q.Pop();
        output(v);
        for(each vertex w adjacent to v){
            if(!visited[w]){
                q.Push(w);
                visited[w]=true; }
        }
    }
    delete [] visited;
}

    講義範例的 BFS 順序為 0 1 2 3 4 5 6 7。

    DFS / BFS 的時間分析結果
    Adjacency matrix找出一個頂點的所有相鄰頂點要 \(O(n)\)，最多拜訪 \(n\) 個頂點\(O(n^2)\)
    Adjacency lists共有 \(n+2e\) 個 chain 節點，每個最多檢查一次\(O(n+e)\)

    Connected Components 與 Spanning Trees

    • 判斷是否 connected：呼叫一次 DFS 或 BFS，看是否還有未拜訪的頂點。
    • 找出所有 connected components：重複呼叫 DFS 或 BFS，每次從一個未拜訪頂點開始，每次呼叫輸出一個 component。
    • Spanning tree：只用 \(E(G)\) 中的邊、包含 \(V(G)\) 所有頂點的樹；有 \(n-1\) 條樹邊，加入任何一條非樹邊都會形成 cycle。
    • 走訪時經過的邊就是樹邊 → DFS spanning tree、BFS spanning tree。

    講義自學主題：sequential lists、adjacency multilists、biconnected components。

    4. 最小生成樹 (Minimum-Cost Spanning Tree)

    對有權重的無向圖，找出邊權總和最小的 spanning tree。三個 greedy 演算法：

    Kruskal's Algorithm

    想法：每次加入一條成本最小的邊；若會形成 cycle 就丟掉；直到有 \(n-1\) 條邊。

    Kruskal's algorithm1. T = ψ
2. While((T contains less than n-1 edges)&&(E is not empty)){
3.     choose an edge (v,w) from E of lowest cost;
4.     delete (v,w) from E
5.     if((v,w) does not create a cycle) add (v,w) to T;
6.     else discard (v,w)
7. }
8. If(T contains less than n-1 edges)
9.     cout << "there is no spanning tree!" <<endl;
    • Step 3、4：用 min heap 存邊的成本，\(O(\log e)\)。
    • Step 5：用集合表示法（Session 6 的 disjoint sets）把同一 connected component 的頂點放在同一集合；要加入的邊 \((v,w)\) 兩端若在同一集合就丟掉，否則合併兩集合，\(O(\log e)\)。
    • 最多執行 \(e-1\) 輪：\((e-1)(\log e+\log e)=O(e\log e)\)。

    Prim's Algorithm

    想法：選出的邊永遠形成一棵樹。從只含任一頂點的樹 \(T\) 開始，每次加入一條成本最小、且加入後 \(T\cup\{(u,v)\}\) 仍是樹的邊，直到 \(T\) 有 \(n-1\) 條邊。

    Prim's algorithm1. V(T) = {0} // start with vertex 0
2. for(T=ψ ; T contains less than n-1 edges; add (u,v) to T){
3.     Let (u,v) be a least cost edge such that u ∈ V(T) and v ∉ V(T);
4.     if(there is no such edge) break;
5.     add v to V(T);
6. }
7. If(T contains fewer than n-1 edges)
8.     cout << "there is no spanning tree!" <<endl;
    • Step 3 用 near-to-tree 陣列記錄每個不在 \(V(T)\)、但與 \(T\) 相鄰的頂點到 \(T\) 的最近距離 → \(O(n)\)。
    • 最多執行 \(n\) 輪：\(O(n^2)\)。
    • 講義範例加入頂點的順序：0 → 5 → 4 → 3 → 2 → 1 → 6，得到成本 99 的 spanning tree。

    Sollin's (Borůvka's) Algorithm

    想法：每個階段選出多條邊。

    1. 從 \(n\) 棵樹（每個頂點自成一棵）組成的 forest 開始
    2. 每棵樹各選一條成本最小的邊
    3. 刪除重複選到的邊；若兩條相同成本的邊連接同樣兩棵樹，只保留一條
    4. 重複直到只剩一棵樹

    5. 最短路徑 (Shortest Paths)

    單一起點：Dijkstra's Algorithm

    給定邊權非負的有向圖與起點 \(v\)，求 \(v\) 到其他每個頂點的最短路徑。

    • 集合 \(S\)：已找到最短路徑的頂點。
    • 陣列 dist：起點到各頂點目前的最短距離；拜訪新頂點時更新： \[\text{dist}[w]=\min\{\text{dist}[u]+\text{length}(u,w),\ \text{dist}[w]\}\] 
    ShortestPath（C++）void MatrixWDigraph::ShortestPath(const int n, const int v)
{ // dist[j], 0 ≤ j < n, stores the shortest path from v to j
  // length[i][j] stores length of edge <i, j>
    for(int i=0; i<n ; i++){ s[i]=false; dist[i]=length[v][i];}
    s[v] = true;
    dist[v] = 0;
    // find n − 1 paths starting from v
    for(int i=0; i<n-1 ;i++){
        // Choose a vertex u, such that dist[u]
        // is minimum and s[u] = false
        int u = Choose(n);
        s[u] = true;
        for(int w=0; w<n; w++)
            if(!s[w] && dist[u] + length[u][w] < dist[w])
                dist[w] = dist[u] + length[u][w];
    }
}
    📝
    例子：從頂點 0 出發的最短路徑
    PathLength
    0, 310
    0, 3, 425
    0, 3, 4, 145
    0, 245
    拜訪順序：{0} → {0, 3} → {0, 3, 4} → {0, 3, 4, 1} → {0, 3, 4, 1, 2}
    ❗
    負權重的邊 講義 p.58：此演算法可能可以用在含負成本邊的有向圖，但限制是有向圖不能有負長度的 cycle。（講義自學主題：處理負邊的 Bellman-Ford 演算法。）

    所有點對：Floyd-Warshall's Algorithm

    可以對 \(n\) 個頂點各做一次單一起點最短路徑，或用 Floyd-Warshall（dynamic programming）。

    💡
    Dynamic Programming Divide-and-conquer 的一種，通常用在最佳化問題；改善「同樣的遞迴呼叫被重複執行」的低效率，適用於子問題共享子子問題時。「Programming」指的是表格法：記住解答，並由下而上 (bottom-up) 計算。
    • \(A^{-1}[i][j]\) = length[\(i\)][\(j\)]
    • \(A^k[i][j]\) = 從 \(i\) 到 \(j\)、中間頂點編號都不大於 \(k\) 的最短路徑長度
    • \(A^{n-1}[i][j]\) = 圖中 \(i\) 到 \(j\) 的最短路徑長度
    \[A^k[i][j]=\min\{A^{k-1}[i][j],\ A^{k-1}[i][k]+A^{k-1}[k][j]\},\quad k\ge 0\]

    直覺：\(A^k[i][j]\) 只有兩種可能 — 路徑不經過第 \(k\) 個頂點，或經過第 \(k\) 個頂點。

    AllLengths（C++）void MatrixWDigraph::AllLengths(const int n)
{ // length[n][n] stores edge length between adjacent vertices
  // a[i][j] stores the shortest path from i to j
    for (int i = 0; i<n; i++)
        for (int j = 0; j<n; j++)
            a[i][j]= length[i][j];          // A^-1

    // path with top vertex index k
    for (int k= 0; k<n; k++)                // A^0 ~ A^(n-1)
        // all other possible vertices
        for (int i= 0; i<n; i++)
            for (int j= 0; j<n; j++)
                if((a[i][k]+a[k][j])<a[i][j])
                    a[i][j] = a[i][k] + a[k][j];
}

    圖邊權非負的有向圖有權重的無向圖
    目標起點到其他每個頂點的最短路徑邊權總和最小的 spanning tree
    演算法Single source：Dijkstra；All-pairs：Floyd-WarshallKruskal、Prim、Sollin（皆為 greedy）

    Transitive Closure

    判斷無權重圖中 \(i\) 到 \(j\) 是否有 path：

    • Transitive closure matrix \(A^+\)：\(A^+[i][j]=1\) 若有長度 \(>0\) 的 path
    • Reflexive transitive closure matrix \(A^*\)：\(A^*[i][j]=1\) 若有長度 \(\ge 0\) 的 path
    • 同樣用 Floyd-Warshall：\(A^k[i][j]=A^{k-1}[i][j]\ \|\ (A^{k-1}[i][k]\ \&\&\ A^{k-1}[k][j])\)

    6. Activity Networks 與 Topological Order

    • 專案可以拆成數個子專案，每個稱為 activity。
    • AOV (Activity-on-Vertex) network：有向圖，頂點代表工作 / 活動，邊代表工作之間的先後關係。
    • Predecessor：頂點 \(i\) 是 \(j\) 的 predecessor iff 有一條從 \(i\) 到 \(j\) 的 directed path。
    • Topological order：頂點的線性排序，使得若 \(i\) 是 \(j\) 的 predecessor，則 \(i\) 排在 \(j\) 前面。
    📝
    例子：資工學位的課程先修關係 例如 C3 Data Structures 需要先修 C1 Programming I、C2 Discrete Mathematics；C7 Analysis of Algorithms 需要 C3、C6。用 topological ordering 產生的線性順序，就是一種修完所有課程的可能方式。

    求 topological order：反覆挑出一個沒有 predecessor 的頂點 \(v\)；在 adjacency lists 的每個頂點多一個欄位 count 記錄 in-degree。

    講義自學主題：AOE (Activity-on-Edge) networks、critical path analysis。

    自我測驗

    Q1. \(n\) 個頂點的無向圖與有向圖最多各有幾條邊？

    無向圖 \(n(n-1)/2\)；有向圖 \(n(n-1)\)。

    Session7-Graphs_240508_093837.pdf p.8

    Q2. DFS 用 adjacency matrix 與 adjacency lists 的時間各是多少？

    Adjacency matrix \(O(n^2)\)；adjacency lists \(O(n+e)\)（\(n+2e\) 個節點各檢查最多一次）。BFS 的時間與 DFS 相同。

    Session7-Graphs_240508_093837.pdf p.33–34, p.37

    Q3. Kruskal 演算法用了哪兩個資料結構？時間複雜度？

    Min heap（取出成本最小的邊）與集合表示法（判斷是否形成 cycle）；\(O(e\log e)\)。

    Session7-Graphs_240508_093837.pdf p.46–47

    Q4. Prim 演算法的 near-to-tree 陣列記錄什麼？時間複雜度？

    記錄不在 \(V(T)\) 但與 \(T\) 相鄰的頂點到 \(T\) 的最近距離；\(O(n^2)\)。

    Session7-Graphs_240508_093837.pdf p.49, p.51

    Q5. 寫出 Floyd-Warshall 的遞迴式，並說明 \(A^k[i][j]\) 的意義。

    \(A^k[i][j]=\min\{A^{k-1}[i][j],A^{k-1}[i][k]+A^{k-1}[k][j]\}\)；\(A^k[i][j]\) 是從 \(i\) 到 \(j\)、中間頂點編號都不大於 \(k\) 的最短路徑長度。

    Session7-Graphs_240508_093837.pdf p.62

    Q6. 什麼是 topological order？要怎麼求？

    頂點的線性排序，使每個 predecessor 都排在它的後繼之前。反覆挑出沒有 predecessor（in-degree = 0）的頂點，用 count 欄位記錄 in-degree。

    Session7-Graphs_240508_093837.pdf p.72, p.75
