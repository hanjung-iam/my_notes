    重點摘要

    • BST 的操作都是 \(O(h)\)，\(h\) 可能高達 \(n\)；用 AVL tree、B-tree、B+-tree 保持平衡。
    • AVL tree：每個節點 \(|bf|\le 1\)，\(bf=\text{height}(T_L)-\text{height}(T_R)\)；失衡時用旋轉修正。
    • 四種失衡：outside cases LL、RR 用單次旋轉；inside cases LR、RL 需要兩次旋轉。
    • B-tree（order \(m\)）：所有 leaf 在同一層，每個節點最多 \(m\) 個 children；溢位時分裂並把中間 key 往上推。
    • B+-tree：資料指標只在 leaf，leaf 串成 linked list（sequence set）；層數可以比 B-tree 少。

    1. 為什麼需要平衡

    • BST 的所有操作都是 \(O(h)\)，\(h\) = BST 的高度。
    • Worst case \(h=n\)（依序插入 1, 2, …, \(n\)）；Best case \(h=\log n\)（插入 4, 2, 6, 1, 3, 5, 7）。
    • 保持 BST 平衡的方法：AVL Trees、B Trees（multiway search trees）、B+ Trees。

    2. AVL Trees

    Height Balanced

    • 空樹是 height balanced。
    • 非空 binary tree \(T\)，左右子樹為 \(T_L\)、\(T_R\)，balance factor： \[bf(T)=\text{height}(T_L)-\text{height}(T_R)\]
    • \(T\) 是 height balanced iff (1) \(T_L\) 與 \(T_R\) 都是 height balanced，且 (2) \(|bf(T)|\le 1\)。

    AVL tree 是 height-balanced 的 binary search tree；每個節點存目前的高度，用來計算 balance factor。

    Rebalancing

    在 BST 插入 / 刪除時，若 balance factor > 1 或 < −1，就啟動 rebalance，用旋轉 (rotation) 修正。

    情況新節點插入在 A 的…修正方式
    LL（outside）左子樹的左子樹Right rotation（單次）
    RR（outside）右子樹的右子樹Left rotation（單次）
    LR（inside）左子樹的右子樹Left rotation + Right rotation
    RL（inside）右子樹的左子樹Right rotation + Left rotation
    ❗
    易錯：inside case 只轉一次會失敗 例：4 → 8 → 6 這種 inside case，只做一次 left 或 right rotation 仍然不平衡（講義稱為 wrong concept）。要先對選定區域做一次旋轉，再對整體做反方向的旋轉。 
    AVLTree::rebalance（C++）template < class T >
TreeNode<T>* AVLTree<T>::rebalance(TreeNode<T> *node){
    // LL Rotation
    if ( node->bf()>1 && node->left->bf()>=0 ){
        return rightRotate( node );
    }
    // RR Rotation
    if ( node->bf()<-1 && node->right->bf()<=0 ){
        return leftRotate( node );
    }
    // LR Rotation
    if ( node->bf()>1 && node->left->bf()<0 ){
        node->left = leftRotate( node->left );
        return rightRotate( node );
    }
    // RL Rotation
    if ( node->bf()<-1 && node->right->bf()>0 ){
        node->right = rightRotate( node->right );
        return leftRotate( node );
    }
}
    leftRotate（C++，rightRotate 左右對稱）template < class T >
TreeNode<T>* AVLTree<T>::leftRotate(TreeNode<T> *node)
{
    TreeNode<T>* node_r = node->right;
    TreeNode<T>* node_rl = node_r->left;
    node_r->left = node;
    node->right = node_rl;
    node->UpdateHeight();
    node_r->UpdateHeight();
    return node_r;
}

    Insert / Delete：先做一般的 BST insert / delete，再從該節點往 root 更新高度並 rebalance。

    3. B-Tree

    Order 為 \(m\) 的 B-tree 是 height-balanced 的樹，每個節點最多 \(m\) 個 children，且：

    1. 所有 leaf 都在同一層
    2. 沒有節點超過 \(m\) 個 children
    3. 除了 root 以外，所有節點至少有 \(\lceil m/2\rceil-1\) 個 keys
    4. root 要嘛是 leaf，要嘛有 2 到 \(m\) 個 children

    第 3 點：\(m/2\) 先向上取整再減 1。講義範例 \(m=4\) 時，每個節點的 key 數為 1~3。

    Insert

    1. 搜尋，把新 key 插入 leaf。
    2. 若 leaf 溢位：把 leaf 分成兩個，並把中間的 key 往上推到 parent。
    3. 若 parent 也溢位：同樣分裂並往上推，可能一路重複到 root。
    4. 必要時 root 也分裂，中間 key 推到新的 root，樹高增加一層。

    Delete

    情況處理方式
    刪除的是 leaf 中的 key刪除後若 key 數仍合法就完成；若 underflow：sibling 的 key 夠多就 redistribute（向 sibling 借），否則 merge 成一個節點，再檢查 parent 是否 underflow
    刪除的是 non-leaf 中的 key與 logic next key（右子樹最左 leaf 的第一個 key）交換，再刪除 leaf 中的 key；也可以改用 logic previous key（左子樹最右 leaf 的最後一個 key）

    講義例：刪除 41 造成 underflow，且無法 redistribute → Case 3 merge。

    Session10 - Advanced Topics_240529_093517.pdf p.21–28

    4. B+-Tree

    B-tree 的變形，有兩種節點：

    節點內容用途
    Index (non-leaf) nodes只存 keys引導搜尋到 leaf 中的記錄（direct search）
    Data (leaf) nodes存資料記錄（實際資料或資料指標），並串成 linked list（sequence set）循序存取（sequential retrieval）
    • Insert 的流程與 B-tree 相同（搜尋 → 插入 leaf → 溢位就分裂 → 檢查 parent）。講義例：\(m=5\) 時插入 8* 造成分裂。
    • Delete：underflow 時 redistribute 或 merge。在 leaf（data entries）層 merge 時，parent 的 key 會被丟掉，這點和 B-tree 不同（講義例：刪除 24）。
    B-treeB+-tree
    指向資料記錄的指標存在樹的每一層只存在 leaf 層
    層數—可以比對應的 B-tree 少（或能容納更多搜尋值）

    自我測驗

    Q1. AVL tree 的 balance factor 怎麼算？什麼情況要 rebalance？

    \(bf(T)=\text{height}(T_L)-\text{height}(T_R)\)；balance factor > 1 或 < −1 時要 rebalance。

    Session10 - Advanced Topics_240529_093517.pdf p.4, p.7

    Q2. LR 情況是什麼？要怎麼旋轉？

    新節點插在 A 的左子樹的右子樹；先對左子樹做 left rotation，再對 A 做 right rotation。

    Session10 - Advanced Topics_240529_093517.pdf p.14, p.18

    Q3. B-tree 插入時 leaf 溢位要怎麼處理？

    把 leaf 分成兩個，中間的 key 往上推到 parent；若 parent 也溢位就重複，必要時 root 分裂，樹高加一。

    Session10 - Advanced Topics_240529_093517.pdf p.23

    Q4. B-tree 刪除 non-leaf 的 key 時怎麼做？

    先與 logic next key（右子樹最左 leaf 的第一個 key）或 logic previous key 交換，再當成刪除 leaf 的 key 處理。

    Session10 - Advanced Topics_240529_093517.pdf p.28

    Q5. B-tree 與 B+-tree 最主要的差別？

    B-tree 每一層都有指向資料記錄的指標；B+-tree 只有 leaf 層有，且 leaf 串成 linked list，層數可以比 B-tree 少。

    Session10 - Advanced Topics_240529_093517.pdf p.30, p.35
