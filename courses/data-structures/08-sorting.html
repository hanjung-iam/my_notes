    排序 編碼

    重點摘要

    • Internal sort 全部在主記憶體完成；external sort 需要讀寫磁碟（用 merge sort）。
    • Stable sort：key 相同的記錄，排序後維持原本的先後順序。Insertion、Merge 是 stable；Quick、Heap 不是。
    • 只用比較與交換的排序，最好只能做到 \(\Omega(n\log n)\)（decision tree）。
    • Worst / Average：Insertion \(n^2/n^2\)；Heap、Merge \(n\log n/n\log n\)；Quick \(n^2/n\log n\)；Radix \(nk/nk\)。
    • Merge runs 或 Huffman 編碼：反覆合併最小的兩個，讓 weighted external path length 最小。

    1. 為什麼要排序

    • 在每筆記錄有一或多個 key 的串列中找特定 key：sequential search 由左到右（或反向）找，\(O(N)\)。
    • 改善：先把串列排序再搜尋。可以依排序規則插入（retrieval 時間要小），或一批插入後再排序（插入時間要小、很少 retrieval）。
    類別說明適用種類
    Internal sort整個排序在主記憶體完成小串列（例如 1MB）Insertion、Merge、Heap、Radix sort
    External sort排序過程中需要資料 I/O大串列（例如 1T）Merge sort
    💡
    Stable sort 若 \(r_i=r_j\) 且輸入中 \(r_i\) 在 \(r_j\) 之前，則排序後 \(r_i\) 仍在 \(r_j\) 之前。例：21, 4, 5, 78, 5, 12 → 4, 5, 5, 12, 21, 78。

    Session8 - Sorting_240526_172425.pdf p.3–6

    2. Insertion Sort

    把輸入分成左邊已排序、右邊未排序兩部分；每次從右邊取一個元素，插入左邊正確的位置。

    Insertion Sort（C++）template <class T>
void Insert(const T& e, T *a, int i){
    a[0] = e;
    while (e < a[i]) {
        a[i+1] = a[i];
        i--; }
    a[i+1] = e;
}
template <class T>
void InsertionSort(T *a, const int n){
    for (int j = 2; j <= n ; j++){
        T temp = a[j];
        Insert(temp, a, j - 1);}
}
    • Worst case：外層 \(O(n)\)、內層 \(O(j)\) → \(O(n^2)\)；Average case 也是 \(O(n^2)\)。
    • Stable。

    Session8 - Sorting_240526_172425.pdf p.8–10

    3. Quick Sort

    Divide and conquer，使用一個 pivot：pivot 左邊的記錄 ≤ pivot，右邊的記錄 > pivot。步驟：找出 pivot 的位置，再遞迴排序兩個子串列。

    QuickSort（C++）template <class T>
void QuickSort(T *a, const int left, const int right)
{   if (left < right) {
        int i = left, j = right + 1, pivot = a[left];
        do {
            do i++; while (a[i] < pivot);
            do j--; while (a[j] > pivot);
            if (i < j) swap (a[i], a[j]);
        } while (i < j);
        swap (a[left], a[j]);
        QuickSort(a, left, j - 1);
        QuickSort(a, j + 1, right);
    }
}
    📝
    例子：pivot = 26
    • 26 5 37 1 61 11 59 15 48 19 → 交換 37、19
    • 26 5 19 1 61 11 59 15 48 37 → 交換 61、15
    • 26 5 19 1 15 11 59 61 48 37 → \(i\ge j\)，交換 a[left] 與 a[j]
    • 11 5 19 1 15 26 59 61 48 37 → 再分別遞迴排序左右兩邊
    • 若切割點在中間：遞迴深度 \(O(\log n)\)，每層找切割點 \(O(n)\) → 平均 \(O(n\log n)\)。
    • Worst case：\(O(n^2)\)。
    • 找更好的切割點：取 median{first, middle, last}。
    • Not stable。

    Session8 - Sorting_240526_172425.pdf p.12–16

    4. 排序的下界

    • 若排序過程只使用比較與交換，\(\Omega(n\log n)\) 是最好的可能時間。
    • Decision tree：描述排序過程的樹；每個 vertex 是一次比較，每個 branch 是比較的結果。講義以 3 個 key 的 insertion sort 畫出 decision tree。
    • \(n\) 筆記錄有 \(n!\) 種排列 → decision tree 有 \(n!\) 個 leaf → 平均 root-to-leaf 路徑為 \(\Omega(n\log n)\)。
    ⚠️
    待確認 p.20 寫「The height (depth) of the tree is \(n\log n\)」。演算法課 Lecture 07 p.12 的寫法是「node-height \(\ge\log(n!)\ge(n/2)\log(n/2)=\Omega(n\log n)\)」，兩者表述不同，請對照講義確認。

    Session8 - Sorting_240526_172425.pdf p.18–20；Algo-Lecture-07.pdf p.12

    5. Merge Sort

    把已排序的串列合併成一個排序好的串列；divide and conquer：一直切到串列已排序，再遞迴合併。Stable。

    Merging

    合併兩個排序好的串列，作法類似多項式加法；兩串列大小為 \(m\)、\(l\) 時，合併時間 \(O(m+l)\)。

    Merge（C++）template <class T>
void Merge(T *initList, T *mergedList, const int l, const int m, const int n)
{   for (int i1 = l, iResult = l, i2 = m + 1; i1 <= m && i2 <= n; iResult++)
        if (initList[i1] <= initList[i2]){
            mergedList[iResult] = initList[i1];
            i1++;
        }else{
            mergedList[iResult] = initList[i2];
            i2++;}
    // copy the remaining records, if any, of 1st list
    copy (initList + i1, initList + m + 1, mergedList + iResult);
    // copy the remaining records, if any, of 2nd list
    copy (initList + i2, initList + n + 1, mergedList + iResult);
}

    Iterative Merge Sort

    把串列看成 \(n\) 個已排序的子串列；第 1 輪兩兩合併得到 \(n/2\) 個，第 2 輪得到 \(n/4\) 個…直到只剩一個。

    📝
    MergePass 例子
    • 26 | 5 | 77 | 1 | 61 | 11 | 59 | 15 | 48 | 19
    • 5, 26 | 1, 77 | 11, 61 | 15, 59 | 19, 48
    • 1, 5, 26, 77 | 11, 15, 59, 61 | 19, 48
    • 1, 5, 11, 15, 26, 59, 61, 77 | 19, 48
    • 1, 5, 11, 15, 19, 26, 48, 59, 61, 77
    • Merge pass 的次數 \(O(\log n)\)，每個 merge pass \(O(n)\) → \(O(n\log n)\)。
    • 需要額外空間存放合併結果。

    Recursive Merge Sort

    把串列分成大致相等的左右兩半，遞迴排序兩個子串列，再合併。講義實作用 link[] 陣列串起排序結果（rMergeSort + ListMerge），回傳排序後串列第一個元素的 index。

    rMergeSort（C++）template <class T>
int rMergeSort(T* a, int* link, const int left, const int right)
{ // sorting a[left:right]. link[i] is initialize to 0.
  // rMerge returns the index of 1st element in the sorted list.
    if (left >= right) return left;
    int mid = (left + right) /2;
    return ListMerge(a, link,
        rMergeSort(a, link, left, mid),       // sort left sublist.
        rMergeSort(a, link, mid + 1, right)); // sort right sublist.
}

    6. Heap Sort

    • 利用 max-heap：插入與刪除都是 \(O(\log n)\)。
    • 把 \(n\) 筆記錄逐一插入建立 max-heap：\(O(n\log n)\)；反覆從 max-heap 移除最大的記錄（root）：\(O(n\log n)\)。
    • Not stable。
    HeapSort（C++）template <class T>
void HeapSort(T *a, const int n)
{
    Heapify(a, n);
    for (i = n-1; i >= 1; i--)  // Sorting
    {
        swap(a[1], a[i+1]);     // swap the root with last node
        Heapify(a, i);          // rebuild the heap (a[1:i])
    }
}

    Session8 - Sorting_240526_172425.pdf p.36–38

    7. 多個 key 的排序與 Radix Sort

    記錄依 keys \(K_1,K_2,\dots,K_r\) 排序：對每一對 \(i<j\)，\((K_i^1,\dots,K_i^r)\le(K_j^1,\dots,K_j^r)\)。例：撲克牌有兩個 key，K1 花色 ♣ < ♦ < ♥ < ♠、K2 點數 2 < 3 < … < K < A，排序結果為 2♣, …, A♣, …, 2♠, …, A♠。

    方法步驟
    MSD (Most-significant-digit) sort先依 K1 分成 4 堆 → 每堆再分成小堆 → 依序疊起來
    LSD (Least-significant-digit) sort先依 K2 分成 13 堆並疊好（3 放在 2 上面…A 放在 K 上面）→ 再對 K1 做 stable sort 得到 4 堆 → 疊起來
    • Bin Sort (Bucket Sort)：記錄來自大小為 \(m\) 的集合 \(\{1,\dots,m\}\)；建立 \(m\) 個 bucket，把 a[\(i\)] 放進第 a[\(i\)] 個 bucket，再把所有 bucket 串起來。適合 \(m\) 小的情況。
    • Radix Sort：用某個 radix (base) \(r\) 把 key 拆成 subkeys，以 MSD 或 LSD 順序套用 bin sort。適合數值範圍很大的數字。時間 \(O(d(n+r))\)。
    • 講義的 LSB radix sort 實作用 link[] 串起元素，每個 bin 用 f[k]（head）與 e[k]（tail）記錄，從最低位到最高位做 \(d\) 輪。
    ⚠️
    待確認 p.43 寫「Create r-1 buckets」，但 p.45 的程式宣告 int e[r], f[r];（\(r\) 個 bin，digit 範圍為 \([0,r)\)），兩處數量不一致，請對照講義確認。

    Session8 - Sorting_240526_172425.pdf p.40–46

    8. Internal Sorting 總結

    方法WorstAverageStable
    Insertion Sort\(n^2\)\(n^2\)是
    Heap Sort\(n\log n\)\(n\log n\)否
    Merge Sort\(n\log n\)\(n\log n\)是
    Quick Sort\(n^2\)\(n\log n\)否
    Radix Sort\(nk\)\(nk\)—

    講義實測（單位依講義）：\(n=5000\) 時 Insert 15.935、Heap 1.410、Merge 1.271、Quick 0.970；\(n=50\) 時 Insert 0.004 最快。

    💡
    Design Guidelines
    • Insertion sort 適合 \(n\) 很小，或串列已部分排序的情況。
    • Merge sort 比 heap sort 稍快，但需要額外空間。
    • 平均而言 Quick sort 表現最好。

    Session8 - Sorting_240526_172425.pdf p.47–50

    9. External Sort

    • 串列太大無法全部載入記憶體（可能在磁碟上）：讀入部分記錄 → 排序 → 寫回磁碟。
    • Block：一次讀寫的資料單位。
    • 演算法：用 internal sort 把輸入切成多個已排序的片段（runs），再依 merge tree 合併。
    • 為什麼用 merge sort？子串列可以各自排序再合併；合併時只需要把兩個 run 的開頭記錄載入記憶體。
    📝
    例子 記憶體 750 筆記錄、block 大小 250 筆，要排序 4500（250×18）筆。合併 R1、R2 時：先把兩者的第一個 block 讀入 input buffer，合併結果寫到 output buffer；output buffer 滿了就寫回磁碟，input buffer 空了就讀入下一個 block。

    Optimal Merging of Runs

    Runs 大小不同時，不同的合併順序會有不同的執行時間。總合併量為 weighted external path length：

    \[\sum_{i=1}^{n}s_id_i\]

    其中 \(s_i\) 是 Run \(i\) 的大小、\(d_i\) 是該節點到 root 的距離。最小化方法：把 runs 依大小排序，取兩個最小的合併成一棵樹，重複直到只剩一棵樹（例：2, 4, 5, 15 → 6 → 11 → 26）。

    Session8 - Sorting_240526_172425.pdf p.52–58

    10. Message Encoding 與 Huffman Codes

    • 給定訊息 \(\{M_1,\dots,M_i\}\)，要用唯一的二進位碼編碼每個訊息。
    • Huffman codes：用一棵 binary tree（decode tree）來編碼。
    • 解碼成本與碼的 bit 數成正比；若 \(M_i\) 的傳送頻率為 \(q_i\)，總成本為 \(\sum_{i=1}^{n}q_id_i\)。
    • 建 decode tree 的方法同 optimal merge：依 \(q_i\) 排序，取兩個 \(q_i\) 最小的合併，重複直到只剩一棵樹。
    📝
    例子：M1 = 1/7、M3 = 1/7、M2 = 2/7、M4 = 3/7 講義列出兩種等價的 Huffman code：(M1, M2, M3, M4) = (111, 10, 110, 0) 或 (000, 01, 001, 1)，出現最頻繁的 M4 只用 1 個 bit。

    Session8 - Sorting_240526_172425.pdf p.60–64

    自我測驗

    Q1. 什麼是 stable sort？Insertion、Quick、Merge、Heap 哪些是 stable？

    key 相同的記錄排序後維持原本先後順序。Insertion、Merge 是 stable；Quick、Heap 不是。

    Session8 - Sorting_240526_172425.pdf p.6, p.10, p.16, p.22, p.36

    Q2. Quick sort 的 worst 與 average 時間？如何找比較好的 pivot？

    Worst \(O(n^2)\)、average \(O(n\log n)\)。取 median{first, middle, last}。

    Session8 - Sorting_240526_172425.pdf p.15–16

    Q3. 為什麼 external sort 使用 merge sort？

    子串列可以各自排序再合併；合併時只需要把兩個 run 的開頭記錄載入記憶體。

    Session8 - Sorting_240526_172425.pdf p.53

    Q4. LSD sort 排撲克牌的步驟？為什麼第二步要 stable？

    先依點數 K2 分 13 堆並疊好，再依花色 K1 做 stable sort 得到 4 堆後疊起來。要 stable 才能保留第一步依點數排好的順序。

    Session8 - Sorting_240526_172425.pdf p.41

    Q5. 如何建出讓 weighted external path length 最小的 merge tree / decode tree？

    依大小（或頻率）排序，每次取最小的兩個合併成一棵樹，重複直到只剩一棵樹。

    Session8 - Sorting_240526_172425.pdf p.58, p.63
