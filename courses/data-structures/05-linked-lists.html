    重點摘要

    • Array 適合隨機存取，但在任意位置插入/刪除很困難；Linked list 的節點不必連續，每個節點存下一個節點的位址。
    • 用 ChainNode（data + link）與 Chain（first、last）兩個 class 實作；支援 InsertBack、Concatenate、Reverse 等操作。
    • Circular list：最後一個節點指回第一個；存 last 指標比存 first 方便（\(O(1)\) 取得第一個）。
    • Sparse matrix 用 linked structure：header node + element node（down / right），建立時間 \(O(n+m+r)\)。
    • Doubly linked list：每個節點有左右兩個 link，可雙向移動；Iterator 提供走訪任意容器的統一方式。

    1. Array 與 Linked List

    Array（sequential mapping）Linked List
    儲存方式節點 \(a_i\) 存在位置 \(L_i\)，下一個節點在 \(L_{i+1}\)節點在記憶體中不再連續，每個節點存下一個節點的位址
    優點適合隨機存取；從尾端插入/刪除有效率；適合 Stack 與 Queue—
    缺點在任意位置插入/刪除節點很困難—

    Singly Linked List (SLL)：每個節點恰好有一個指標欄位。

    📝
    例子：串列 BAT → CAT → EAT → FAT → …

    在 CAT 與 EAT 之間插入 GAT

    1. 建立新節點 newNode，data 設為 GAT
    2. newNode 的 link 指向 EAT
    3. CAT 的 link 指向 newNode

    刪除 EAT

    1. 找到 EAT 前一個節點 temp
    2. delnode 設為 temp 的下一個節點
    3. temp 的 link 指向 EAT 的下一個節點
    4. 刪除 EAT（delnode）

    2. Chain 的實作

    • ChainNode class：data 欄位 + link 欄位；Chain class：支援對 ChainNode 的各種操作。
    • 可以讓 Chain 成為 ChainNode 的 friend，或把 ChainNode 寫成 Chain 內的 nested class。
    • 指標操作複習：宣告 NodeA *a1=NULL;、配置 a1 = new NodeA;、釋放 delete a1; a1=NULL;、存取成員 a1->memData 或 (*a1).memData。
    基本操作（C++）void Chain::Create2()
{
    // Create and set the fields of 2nd node
    ChainNode* second = new ChainNode(20,0);
    // Create and set the fields of 1st node
    first = new ChainNode(10,second);
}

void Chain::Insert50(ChainNode *x)
{
    if(first) // Insert after x
        x->link = new ChainNode(50, x->link);
    else      // Insert into empty list
        first = new ChainNode(50);
}

void Chain::Delete(ChainNode *x, ChainNode *y)
{  // x is the node to be deleted and
   // y is the node preceding x
    if(x==first) first = first->link;
    else y->link = x->link;
    delete x;
    x=NULL;
}

    Template Chain：InsertBack、Concatenate、Reverse

    Template 版的 Chain<T> 同時記錄 first 與 last。

    Chain<T> 操作（C++）template < class T >
void Chain<T>::InsertBack(const T& e)
{
    if(first) { // Non-empty chain
        last->link = new ChainNode<T>(e);
        last = last->link;
    }
    else // Insert into an empty chain
        first = last = new ChainNode<T>(e);
}

template < class T >
void Chain<T>::Concatenate(Chain<T>& b)
{  // b is concatenated to the end of *this
    if ( first ) { last->link = b.first; last = b.last; }
    else { first = b.first; last = b.last; }
    b.first = b.last = 0;
}

template < class T >
void Chain<T>::Reverse(void)
{  // Turn a chain,(a1, …, an) into (an, …, a1)
    ChainNode<T> *current = first, *previous = NULL;
    while (current) {
        ChainNode<T> *r = previous;
        previous = current;       // r is behind the previous
        current = current->link;  // move current to next node
        previous->link = r;       // link previous to previous node
    }
    first = previous;
}

    3. Circular Lists

    • Singly-linked circular list：最後一個節點的 link 指向第一個節點。
    • 判斷最後一個節點：if(current->link == first)；可以從任何位置開始走訪。
    • 在最前面插入新節點：新節點的 link 指向 first、first 改為新節點，還要走到最後一個節點，把它的 link 指向新節點。
    💡
    存 last 比存 first 方便 只有 first 時，找最後一個節點要 \(O(N)\)；若有 last 指標，用 last->link 就能在 \(O(1)\) 取得第一個節點。 
    CircularList::InsertFront（C++）template<class T>
void CircularList<T>::InsertFront(const T& e)
{
    ChainNode<T>* newNode = new ChainNode<T>(e);
    if(last){ // nonempty list
        newNode->link = last->link;
        last->link = newNode;
    }
    else{ // empty list
        last = newNode;
        newNode->link = newNode;
    }
}

    4. 用 Linked Structure 表示 Sparse Matrix

    用循序陣列依 row-major 存非零項（見 Session 3）時，要存取特定 column 很困難 → 改用 circular lists 表示。

    節點欄位
    Header node（每個 row / column 各一）down：該 column 第一個非零項；right：該 row 第一個非零項；next：下一個 header node。Row \(i\) 的 header 同時也是 column \(i\) 的 header。
    Element node（每個非零項）row、col、value；down：同一 column 的下一個非零項；right：同一 row 的下一個非零項
    Header of header nodesheader nodes 組成的 circular list 的開頭，存矩陣的維度
    • \(n\times m\) 的稀疏矩陣有 \(r\) 個非零項時，需要的節點總數為 \(\max\{n,m\}+r+1\)。
    • 輸入格式：第一行是矩陣維度與非零項數；之後每行是一個 triple \((i,j,a_{ij})\)，依 row 排序、同 row 內依 column 排序。
    建立步驟時間
    建立 header nodes\(O(\max\{n,m\})\)
    建立非零項節點\(O(r)\)
    關閉 column lists\(O(\max\{n,m\})\)
    連接 header nodes\(O(\max\{n,m\})\)
    總計\(O(\max\{n,m\}+r)=O(n+m+r)\)

    5. Doubly Linked Lists

    每個節點有兩個 link 欄位（left、right），可以往兩個方向走訪；可做成 linear list 或 circular list。

    刪除節點 x / 在 x 之後插入節點 p（C++）// Delete x
x->left->right = x->right;
x->right->left = x->left;
delete x;

// Insert p after x
p->left = x;  p->right = x->right;
x->right->left = p;
x->right = p;

    講義列為自學主題：用 linked list 表示多項式、Linked stacks and queues。

    6. Iterator：走訪容器的元素

    • 輸出所有整數、求最大/最小/平均、求和/乘積/平方和… 這些操作都需要走訪容器中的每個元素。
    • Array 用 for (int i = 0; i < n; i++)；Linked list 用 for (ChainNode<int> *ptr=first; ptr!=0; ptr=ptr->link)。
    • Iterator：指向容器中某個元素的指標；用 * 存取元素，支援前置/後置 ++。
    • 優點：可走訪任意資料型別的容器、保證執行期範圍安全、適用所有 STL 演算法、適合團隊開發；缺點：可能犧牲一些效能。
    C++ Iterator 種類能力
    Input iterator讀取；前置/後置 ++
    Output iterator寫入；前置/後置 ++
    Forward iterator前置/後置 ++
    Bidirectional iterator前置/後置 ++ 與 --
    Random access iterator可以任意跳躍

    所有 iterator 都支援 ==、!=、*。Chain 的 forward iterator 以 nested class ChainIterator 實作，提供 begin()（回傳 ChainIterator(first)）與 end()（回傳 ChainIterator(0)），即可搭配 STL 演算法，例如 std::accumulate(myChain.begin(), myChain.end(), 0)。

    自我測驗

    Q1. Array 和 linked list 各適合什麼情況？

    Array 適合隨機存取、從尾端插入刪除；但在任意位置插入刪除很困難。Linked list 的節點不必連續，插入刪除只需改指標。

    Session5-Linked Lists PPT Handout.pdf p.3, p.5

    Q2. 從 SLL 刪除一個節點 EAT 的步驟？

    找到 EAT 前一個節點 temp → delnode 設為 temp 的下一個 → temp 的 link 指向 EAT 的下一個 → 刪除 EAT。

    Session5-Linked Lists PPT Handout.pdf p.7

    Q3. Circular list 為什麼存 last 指標比較方便？

    有 last 時，last->link 就是第一個節點，\(O(1)\)；只有 first 時要找到最後一個節點需要 \(O(N)\)。

    Session5-Linked Lists PPT Handout.pdf p.23

    Q4. 用 linked structure 表示 \(n\times m\)、\(r\) 個非零項的稀疏矩陣，需要幾個節點？建立的時間？

    \(\max\{n,m\}+r+1\) 個節點；建立時間 \(O(n+m+r)\)。

    Session5-Linked Lists PPT Handout.pdf p.31, p.33

    Q5. Doubly linked list 刪除節點 x 要改哪兩個指標？

    x->left->right = x->right; 與 x->right->left = x->left;，再 delete x。

    Session5-Linked Lists PPT Handout.pdf p.36
