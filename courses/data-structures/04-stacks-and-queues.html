    線性結構 運算式

    重點摘要

    • Stack：插入與刪除都在同一端 (top)，LIFO；Queue：rear 插入、front 刪除，FIFO。
    • 用 template 寫出通用的容器（Bag）；Stack IS-A Bag，可以用繼承表達。
    • Circular queue：rear = (rear+1) % capacity；front == rear 表示空，所以要在真的滿之前就配置更多空間。
    • Postfix 不需要括號、不用管運算子優先順序，用 stack 由左到右掃描一次就能求值。
    • Infix 轉 Postfix：運算元直接輸出，運算子放進 stack，堆疊頂端優先序 ≥ 新運算子時就 pop。

    1. Template 與 Bag 容器

    • Bag：可以插入與刪除元素的容器。講義的整數版 Bag 提供 Size、IsEmpty、Element（永遠回傳第一個元素）、Push、Pop（永遠刪除中間的元素）。
    • 容量不足時用 ChangeSize1D(array, capacity, 2*capacity) 把容量加倍。
    • 用 template<class T> 改寫，就能存放任意型別 T；刪除元素時呼叫解構子 array[top--].~T();。

    Subtype

    • 繼承用來表達 subtype 關係：Type B 的資料物件 IS-A Type A 的資料物件，B 比 A 更特化（例：Chair IS-A Furniture）。
    • Bag 和 Stack 都是可以插入、刪除元素的資料結構，但 Stack 更特化 → Stack IS-A Bag。
    • Bag 的成員函式宣告成 virtual、資料成員宣告成 protected；class Stack : public Bag 只需實作 Bag 沒有的操作（例：Top()）並重新定義 Pop()。

    2. Stack

    Stack 是一個有序串列，插入（addition / push）與刪除（removal / pop）都在同一端進行，這一端稱為 top。運作順序為 Last-In-First-Out (LIFO)。

    Stack ADT 與 Push / Pop（C++）template < class T >
class Stack // A finite ordered list
{
public:
    Stack (int stackCapacity = 10);  // Constructor
    bool IsEmpty ( ) const;          // Check if the stack is empty
    T& Top ( ) const;                // Return the top element
    void Push (const T& item);       // Insert a new element at top
    void Pop ( );                    // Delete one element from top
private:
    T* stack;
    int top;   // init. value = -1
    int capacity;
};

template < class T >
void Stack < T >::Push (const T& x)
{ // Add x to stack
    if(top == capacity - 1)
    {
        ChangeSize1D(stack, capacity, 2*capacity);
        capacity *= 2;
    }
    stack [ ++top ] = x;
}

template < class T >
void Stack < T >::Pop ( )
{ // Delete top element from stack
    if(IsEmpty()) throw "Stack is empty. Cannot delete.";
    stack [ top-- ].~T(); // Delete the element
}

    3. Queue

    Queue 是一個有序串列，插入與刪除在不同端：新元素從 rear 插入、舊元素從 front 刪除。運作順序為 First-In-First-Out (FIFO)。

    Circular Queue

    • 把陣列頭尾相接，插入時 rear = (rear+1) % capacity，刪除時 front = (front+1) % capacity。
    • front 指向第一個元素的前一格，所以 Front() 回傳 queue[(front+1)%capacity]。
    ❗
    易錯：空與滿無法區分 rear == front 表示 queue 是空的；但如果把陣列完全填滿，也會出現 rear == front。所以要在 queue 真的滿之前就配置額外空間（Push 時檢查 (rear+1)%capacity == front）。 
    Queue 的操作（C++）template < class T >
void Queue < T >::IsEmpty() const { return front==rear; }

template < class T >
T& Queue < T >::Front() const {
    if(IsEmpty()) throw "Queue is empty!";
    return queue[(front+1)%capacity];
}

template < class T >
T& Queue < T >::Rear() const {
    if(IsEmpty()) throw "Queue is empty!";
    return queue[rear];
}

template < class T >
void Queue< T >::Push (const T& x)
{ // Add x at rear of queue
    if((rear+1)%capacity == front)
    {
        // queue is going to full, double the capacity!
    }
    rear = (rear+1)%capacity;
    queue [rear] = x;
}

template < class T >
void Queue < T >::Pop ( )
{ // Delete front element from queue
    if(IsEmpty()) throw "Queue is empty. Cannot delete.";
    front = (front+1)%capacity;
    queue[front].~T(); // Delete the element
}

    容量加倍

    📝
    例子：capacity = 8，內容 C D E F G _ A B（front = 5，rear = 4） 容量加倍到 16 後，元素必須重新排列才能維持環狀順序：
    • Scenario 1：把右段（A、B）移到新陣列的最右邊 → front = 13，rear = 4
    • Scenario 2：另一種排列方式 → front = 15，rear = 6

    4. 運算式求值

    • 運算式由運算子（+、-、*、/…）與運算元（A、B、C…）組成；執行順序可能影響最終結果。
    • 求值規則：運算子有優先順序，高的先算；同優先順序由左到右；單元運算子由右到左。
    C++ 優先順序運算子
    1（最高）Minus（負號）、!
    2*、/、%
    3+、-
    4<、<=、>=、>
    5==、!=
    6&&
    7（最低）||

    Infix 與 Postfix

    表示法說明例子
    Infix運算子在兩個運算元中間；用程式求值很困難A+B*C
    Postfix每個運算子都在它的運算元之後ABC*+
    💡
    Postfix 的優點 不需要括號；運算子優先順序不再重要；可以有效率地求值：由左到右掃描，遇到運算元就 push 進 stack，遇到運算子就 pop 出兩個元素計算，再把結果 push 回 stack。
    📝
    例子 Infix A+B–C → Postfix A B + C –，代入 A = 4、B = 3、C = 2，依上述規則用 stack 求值。

    Infix 轉 Postfix

    方法 1：Fully parenthesize

    1. 把運算式完全加上括號，例：((((A / B) – C) + (D * E)) – (A * C))
    2. 把每個運算子移到它對應的右括號位置
    3. 刪除所有括號

    方法 2：更聰明的演算法（只掃描一次，使用 stack）

    • 運算元的順序不變：看到運算元就直接輸出。
    • 用 stack 存放看到的運算子，在適當時機 pop 出來：當 stack 頂端運算子的優先序高於或等於新進來的運算子時就 pop（left-to-right associativity）。
    • 有括號時：( 的優先序最高，一律 push 進 stack；push 進去之後 ( 變成最低優先序；遇到 ) 時一直 pop 運算子，直到遇到對應的 (。

    自我測驗

    Q1. Stack 和 Queue 的運作順序分別是什麼？

    Stack 是 LIFO（插入刪除都在 top）；Queue 是 FIFO（rear 插入、front 刪除）。

    Session4-Stacks and Queues Handout.pdf p.10, p.14

    Q2. 為什麼說 Stack IS-A Bag？

    兩者都是可以插入和刪除元素的資料結構，但 Stack 更特化，所以可以用繼承表達這個 subtype 關係。

    Session4-Stacks and Queues Handout.pdf p.7

    Q3. Circular queue 為什麼要在真正滿之前就擴充？

    因為用 front == rear 判斷空；若完全填滿，也會變成 front == rear，無法區分空與滿。

    Session4-Stacks and Queues Handout.pdf p.19

    Q4. Postfix 表示法有哪些優點？

    不需要括號、不用考慮運算子優先順序，可以由左到右掃描一次、用 stack 有效率地求值。

    Session4-Stacks and Queues Handout.pdf p.33

    Q5. Infix 轉 Postfix 時，遇到 ( 和 ) 要怎麼處理？

    ( 優先序最高，一律 push；push 後變成最低優先序。遇到 ) 時一直 pop 運算子，直到遇到對應的 (。

    Session4-Stacks and Queues Handout.pdf p.39
