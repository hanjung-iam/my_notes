    線性結構 矩陣

    重點摘要

    • Array 表示一個 linear list；sequential mapping 支援有效率的隨機存取，non-sequential mapping（如 linked list）插入刪除較有效率。
    • 多項式兩種表示：存所有係數（好實作，但稀疏時浪費空間）vs 只存非零項（稀疏時較好，滿的時候大小加倍）。
    • 多項式加法像合併兩個排序好的串列：while 迴圈 worst case 執行 \(m+n\) 次。
    • Sparse matrix 只存非零項 (row, col, value)；轉置有 Trivial、Smart \(O(\text{cols}\cdot\text{terms})\)、Fast \(O(\text{terms}+\text{cols})\) 三種。
    • Sparse matrix 相乘：先把 \(b\) 做 Fast Transpose，再用類似多項式加法的方式計算每個 \(c[i][j]\)。

    1. Array 的定義與操作

    • 基本資料結構：陣列（homogeneous / heterogeneous）、List（Stack、Queue）、Tree。
    • Array：表示 linear list 的資料結構，元素可以是相同或不同的資料型別。例：一週的天數、一副牌、電話簿。

    ADT \(\text{array}[n]=\{a_0,a_1,\dots,a_{n-1}\}\) 的常見操作：

    • 求長度 \(n\)；由左到右（或反向）讀取
    • 取出第 \(i\) 個元素、在第 \(i\) 個位置存入新元素（\(0\le i<n\)）
    • 在位置 \(i\) 插入 / 刪除元素
    表示法做法特性
    Sequential mapping元素 \(a_i\) 存在陣列的位置 \(i\)最常用；隨機存取有效率
    Non-sequential mapping例：Linked Lists插入與刪除有效率

    2. 用陣列表示多項式

    \[p(x)=a_0x^{e_0}+a_1x^{e_1}+\cdots+a_nx^{e_n}=\sum_{i=0}^{n}a_ix^{e_i}\]
    • 每個 \(a_ix^{e_i}\) 稱為一個 term，係數為 \(a_i\)。
    • Degree：非零項中最大的指數。例：\(p(x)=x^5+4x^3+2x^2+1\) 有 4 項，係數 1, 4, 2, 1，degree 為 5。
    • 加法：\(a(x)+b(x)=\sum(a_i+b_i)x^i\)；乘法：\(a(x)\cdot b(x)=\sum(a_ix^i\cdot\sum b_jx^j)\)。
    • 例：\(a(x)=x^5+4x^3+2x^2+1\)、\(b(x)=3x^6+4x^3+x\) → \(a(x)+b(x)=3x^6+x^5+8x^3+2x^2+x+1\)（degree 6）。
    Polynomial ADT（C++）class Polynomial {
public:
    Polynomial(void);                 // Construct p(x) = 0
    ~Polynomial(void);                // Destructor
    Polynomial Add(Polynomial poly);  // Return the sum of *this and poly
    Polynomial Mult(Polynomial poly); // Return multiplication of *this and poly
    float Eval(float f );             // Return the evaluation result
private:
    // Array representation
};
    表示法做法優點缺點
    第 1 種 依指數遞減/遞增順序存所有係數：int degree; float coef[MaxDegree+1];，\(\text{coef}[i]=a_{n-i}\) 操作容易實作 稀疏多項式浪費記憶體
    第 2 種 只存非零項，每項存 exponent 與 coefficient：Term* termArray; int capacity; int terms; 多項式稀疏時較好 多項式是滿的時候，大小是第 1 種的兩倍

    多項式加法（第 2 種表示）

    Polynomial::Add（C++）Polynomial Polynomial::Add(Polynomial b)
{ // Return sum of polynomial *this and b
    Polynomial c;
    int aPos = 0, bPos = 0;
    while((aPos < terms) && (bPos < b.terms))
        if(termArray[aPos].exp == b.termArray[bPos].exp){
            float t = termArray[aPos].coef + b.termArray[bPos].coef;
            if(t) c.NewTerm(t, termArray[aPos].exp);
            aPos++; bPos++;}
        else if(termArray[aPos].exp < b.termArray[bPos].exp){
            c.NewTerm(b.termArray[bPos].coef, b.termArray[bPos].exp);
            bPos++;}
        else{
            c.NewTerm(termArray[aPos].coef,termArray[aPos].exp);
            aPos++;}
    // add in remaining terms of *this
    for(; aPos < terms; aPos++)
        c.NewTerm(termArray[aPos].coef, termArray[aPos].exp);
    // add in remaining terms of b
    for(; bPos < b.terms; bPos++)
        c.NewTerm(b.termArray[bPos].coef, b.termArray[bPos].exp);
    return c;}
    • while 迴圈內每個敘述都是 \(O(1)\)。
    • 設 \(a(x)\) 有 \(m\) 項、\(b(x)\) 有 \(n\) 項；每次迭代會前進到 \(a(x)\) 或 \(b(x)\)（或兩者）的下一項 → while 迴圈 worst case 執行 \(m+n\) 次。

    3. 用陣列表示矩陣

    矩陣 \(A_{m\times n}\) 有 \(m\) 列、\(n\) 行，存成二維陣列 a[m][n]，第 \(i\) 列第 \(j\) 行的元素為 a[i][j]。

    操作定義程式（C++，講義）
    Transpose\(C_{n\times m}=A^t_{m\times n}\)，\(c[i][j]=a[j][i]\)兩層迴圈：// O(rows)、// O(cols)
    Addition\(C_{m\times n}=A_{m\times n}+B_{m\times n}\)，\(c[i][j]=a[i][j]+b[i][j]\)兩層迴圈：// O(rows)、// O(cols)
    Multiplication\(C_{m\times p}=A_{m\times n}\times B_{n\times p}\)，\(c[i][j]=\sum_{k=0}^{n-1}a[i][k]\times b[k][j]\)三層迴圈：// O(rows)、// O(b.cols)、// O(cols)
     
    Matrix::Multiply（C++）Matrix Matrix::Multiply(Matrix b){
    Matrix c(rows, b.cols);
    for (i=0; i<rows; i++) {            // O(rows)
        for (j=0; j<b.cols; j++) {      // O(b.cols)
            sum=0;
            for (k=0; k<cols; k++)      // O(cols)
                sum += a[i][k]*b[k][j];
            c[i][j]=sum;
        }
    }
    return c;
}

    （講義在每段程式旁留有「Time complexity」空格；依程式註解與 Session 1 的 Rule of Product 可得各迴圈複雜度相乘。）

    4. 稀疏矩陣 (Sparse Matrix)

    • 有很多 0 元素的矩陣，例如 \(5000\times5000\) 的矩陣只有 100 個非零元素。
    • 用二維陣列表示沒效率：存放與計算 0 元素浪費記憶體與時間。
    • 改為只存非零項：每項為 MatrixTerm {row, col, value}，依 row major 順序存在 smArray。

    三種轉置方法

    方法做法時間
    Trivial Transpose直接把每項的 row、col 對調問題：\(A^T\) 的非零項不再依 row major 順序排列
    Smart Transpose因為 row 與 col 對調，改用 column-major 順序掃描：對每個 column \(c\)，掃過所有項，把 col = \(c\) 的項依序放入\(O(\text{cols}\cdot\text{terms})\)（外層 cols、內層 terms）
    Fast Transpose只需檢查所有項一次，用額外空間 rowSize、rowStart\(O(\text{terms}+\text{cols})\)

    Fast Transpose

    • rowSize[i]：\(A^T\) 第 \(i\) 列的非零項數
    • rowStart[i]：\(A^T\) 第 \(i\) 列的非零項起始位置；\(i>0\) 時 \(\text{rowStart}[i]=\text{rowStart}[i-1]+\text{rowSize}[i-1]\)
    • 再把 \(A\) 的元素一個一個複製到 \(A^T\) 的正確位置。
    📝

    SparseMatrix::FastTranspose（C++）SparseMatrix SparseMatrix::FastTranspose( )
{ // Compute the transpose in O(terms + cols) time
    SparseMatrix b(cols , rows , terms);
    if (terms > 0) {
        int *rowSize = new int[cols];
        int *rowStart = new int[cols];
        // compute rowSize[i]=number of terms in row i of b
        fill(rowSize, rowSize+cols, 0);
        for(int i=0; i<terms; i++) rowSize[smArray[i].col]++;
        // rowStart[i] = starting position of row i in b
        rowStart[0] = 0;
        for(int i=1; i<cols; i++)
            rowStart[i]=rowStart[i-1]+rowSize[i-1];
        for(int i=0; i<terms; i++)
        { // copy terms from *this to b
            int j = rowStart[smArray[i].col];
            b.smArray[j].row = smArray[i].col;
            b.smArray[j].col = smArray[i].row;
            b.smArray[j].value = smArray[i].value;
            rowStart[smArray[i].col]++;} // Increase the start pos by 1
        delete [] rowSize;
        delete [] rowStart;}
    return b;}
    矩陣類型比較
    Dense（terms = rows·cols）Fast 與 Trivial 相同：\(O(\text{rows}\cdot\text{cols})\)；Smart 最慢：\(O(\text{rows}\cdot\text{cols}^2)\)
    Sparse（terms ≪ rows·cols）Fast Transpose 比 Trivial 和 Smart 都快

    Sparse Matrix 相乘

    1. 先算出 \(b\) 的轉置 \(b^T\)（用 FastTranspose，\(O(\text{b.terms}+\text{b.cols})\)）。
    2. 對 \(a\) 的每一列 \(i\)、\(b^T\) 的每一列 \(j\)，用類似「多項式加法」的方式計算 \(c[i][j]\)（例：\((2)(4)+(7)(5)=43\)）。
    SparseMatrix::Multiply（講義 pseudocode）SparseMatrix SparseMatrix::Multiply(SparseMatrix b)
{ // Compute the transpose of b
    SparseMatrix bT = b.FastTranspose();    // O(b.terms + b.cols)
    for ith row in smArray                  // O(rows)
        for jth row in bT.smArray           // O(b.cols)
            Perform "Polynomal Addition"    // O(Terms[i] + b.Terms[j])
}

    複雜度：\(O(\text{rows}\cdot\text{b.cols}\cdot(\text{Terms}[i]+\text{b.Terms}[j]))\)，其中 \(\text{rows}\cdot\text{Terms}[i]=\text{a.terms}\)、\(\text{b.cols}\cdot\text{b.Terms}[j]=\text{b.terms}\)。完整程式請參考課本。

    自我測驗

    Q1. Sequential mapping 和 non-sequential mapping 各有什麼優點？

    Sequential mapping 隨機存取有效率（最常用）；non-sequential mapping（如 linked list）插入與刪除有效率。

    Session3-Arrays Handout.pdf p.5

    Q2. 多項式的第 2 種表示法（只存非零項）什麼時候比較差？

    多項式是滿的（非零項很多）時，所需空間是第 1 種表示法的兩倍。

    Session3-Arrays Handout.pdf p.11

    Q3. Trivial transpose 有什麼問題？

    直接對調 row、col 後，\(A^T\) 的非零項不再依 row major 順序排列。

    Session3-Arrays Handout.pdf p.26

    Q4. Fast transpose 用了哪兩個額外陣列？時間複雜度？

    rowSize（\(A^T\) 各列非零項數）與 rowStart（各列起始位置，\(\text{rowStart}[i]=\text{rowStart}[i-1]+\text{rowSize}[i-1]\)）。時間 \(O(\text{terms}+\text{cols})\)。

    Session3-Arrays Handout.pdf p.29

    Q5. 對 dense matrix 而言，三種轉置方法的時間如何？

    Fast 與 Trivial 相同，都是 \(O(\text{rows}\cdot\text{cols})\)；Smart 最慢，\(O(\text{rows}\cdot\text{cols}^2)\)。

    Session3-Arrays Handout.pdf p.32
