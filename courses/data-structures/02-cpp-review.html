    C++ 物件導向

    重點摘要

    • Data Abstraction：規格與實作分離；Data Encapsulation：對外隱藏實作細節。
    • Reference vs Pointer：pointer 可以是 NULL、可以改指向；reference 不能是 NULL、初始化時就必須綁定且不能改。
    • C++ 用 new / delete 動態配置記憶體；用 new 產生的指標一定要 delete（陣列用 delete []）。
    • Class：constructor 建立物件時呼叫、destructor 物件離開 scope 或被刪除時呼叫；編譯器會自動產生 4 個預設方法。
    • Inheritance 是 IS-A 關係；Static polymorphism（overloading，編譯時決定）vs Dynamic polymorphism（virtual，執行時決定）。

    1. 程式設計典範與物件導向

    • Declarative programming：表達計算的邏輯，不描述控制流程（例：Database）。
    • Imperative programming：用敘述改變程式的狀態。
    Algorithmic DecompositionObject-Oriented Decomposition
    拆解方式把軟體拆成步驟，步驟用函式實作把軟體拆成物件，物件互動來解決問題
    例子C、PascalC++
    資料資料結構是次要考量；所有步驟都看得到、存取得到資料，無法阻止不相關的程式碼存取重用性與彈性高
    • Object：做計算的基本單位，包含資料與程序函式。
    • OOP：物件是基本建構單元；每個物件都是某個 class 的 instance；class 之間有繼承關係。
    • Object-Oriented Language（C++）：支援物件、物件須屬於 class、支援繼承。Object-Based Language（講義例：Java）：支援物件、物件須屬於 class。
    • C++ 由 Bjarne Stroustrup 創造，是 C 的強化版；標準有 C++98、C++03、C++TR1、C++11、C++14、C++17、C++20、C++23。

    2. Data Type 與 ADT

    概念意義講義比喻
    Data Abstraction資料物件的規格與實作分離只知道按鈕做什麼，不知道怎麼做到
    Data Encapsulation（Information Hiding）對外部隱藏實作細節透過按鈕互動，不碰內部電路（不允許打開外殼）
    • Data type = 一組物件 + 一組操作。例：int 的物件為 0, +1, -1, …, MAXINT, MININT；操作為 +, -, *, /, ==, <= 等。
    • C++ 基本型別：char、int、float、double…；修飾詞：short、long、signed、unsigned。
    • 資料分組：Array（相同基本型別的元素集合）、struct（C）與 class（C++）。
    💡
    ADT 的優點 簡化；每個物件可以分開測試與除錯；重用性；彈性（可以自由修改內部實作而不影響其他程式碼）。

    3. 基本 C++

    程式組織與 Scope

    • Source file（*.cpp）存放原始碼；Header file（*.h）存放宣告，用 #ifndef / #define / #endif 避免重複引入。
    • Scope：Local scope（區塊內宣告）、Class scope、Namespace scope、File scope。
    • 資料宣告：常數值（5、'a'、4.3）、變數（double income;）、常數變數（宣告時就固定，const int MAX=500;）、列舉型別（enum semester {SUMMER, FALL, SPRING};）。
    • 註解：// 單行；/* */ 多行。
    • 函式由函式名稱、參數列（輸入）、回傳型別（輸出）或 void、函式本體組成。

    Pointer 與 Reference

    • Pointer：存放物件的記憶體位址，例如 int i = 25; int* np; np = &i;
    • Reference（C++ 才有）：物件的別名 (alias)，例如 int i=5; int& j=i; i=7; cout << j;

ptr = &x ;

    參數傳遞與 Overloading

    • Call by value：值被複製到區域儲存空間，不會修改原本的資料。
    • Call by pointer：會修改原本的物件（例：swap(int *a, int *b)）。
    • Function overloading：C++ 可以定義同名但參數不同的函式（例：Max(int, int)、Max(int, int, int)、Max(float, int)…）；C 不行。

    動態記憶體配置

    • C：malloc、free、realloc… 有 memory leak 與 memory fragmentation 問題。
    • C++：使用關鍵字 new 與 delete。
    C++（講義範例）int * y = new int ;
delete y ;
// allocate an int array.
int * data = new int [10];
/* make sure you use 'delete' for pointer generated by 'new'. */
delete [] data ;

    例外處理

    • 用來處理執行期錯誤或特殊狀況，讓程式邏輯更清楚。
    • 每個 try 區塊後面接零或多個 catch 區塊，依序檢查直到型別相符。
    • catch (char* e) 捕捉 char* 型別；catch (bad_alloc e) 捕捉系統定義的 bad_alloc；catch (…) 捕捉所有例外。
    • throw 之後的敘述不會執行，例外會往呼叫者一路傳遞（講義 p.31 以 main → func1 → func2 示範）。

    4. C++ Class

    Class 支援 data abstraction 與 encapsulation：規格放在 header file（例：Rectangle.h），實作放在 source file（例：Rectangle.cpp）。

    Rectangle.h（講義範例）class Rectangle {
public:   // the following members are public
    Rectangle ( );        // constructor
    ~Rectangle( );        // destructor
    int GetHeight ( );    // return the height of the rectangle
    int GetWidth ( );     // return the width of the rectangle
private:  // the following members are private
    int xLow, yLow, height, width;
    // (xLow, yLow) are the coordinates of the bottom left corner of rec.
};

// Rectangle.cpp
int Rectangle::GetHeight() {return height;}
int Rectangle::GetWidth() {return width;}
    • 成員函式在 class 定義外實作時，要加上 Rectangle:: 前綴。
    • 存取成員：物件用 .；透過指標用 ->。
    • private 成員在 class 外存取會 compile error（C 的 struct 沒有這種保護）。

    5. 繼承與多型

    • Inheritance：定義物件間的 IS-A 關係。若 B 是 A 的特化版本（A 比 B 一般），則 B IS-A A；A 的成員（資料與函式）會隱含地複製到 B → 程式碼重用。
    • 例：Polygon（base class）→ Triangle、Rectangle（derived class）。
    • 繼承時可以用 public、protected、private 三種 access specifier（class Triangle : public Polygon）。
    • Specialization：把非共用成員放在 base class 的 private 區塊（derived class 無法存取）；在 derived class 重新宣告成員 = overriding。Overriding 後仍可用 Polygon::CalArea(); 呼叫 base class 的版本。
    ⚠️
    待確認 p.46–48 以圖示說明三種 access specifier 下，base class 的 private / protected / public 成員（x、y、z）在 derived class 中變成什麼存取層級；這些對應關係在 PDF 中沒有可讀取的文字，請對照講義圖示。

    Dynamic Binding 的優點缺點
    理想的 data abstraction；OOP 的強大機制（Design Pattern）；廣泛用於大型軟體設計效能下降：需要額外記憶體存 virtual function table，存取時也有額外的執行成本

    自我測驗

    Q1. Data abstraction 和 data encapsulation 有什麼不同？

    Data abstraction 是把資料物件的規格與實作分開；data encapsulation 是對外部隱藏實作細節。

    Session2 - C++ Review Handout.pdf p.11

    Q2. 列出 pointer 和 reference 的三個差異。

    Pointer 可以是 NULL，reference 不行；reference 初始化時必須綁定變數；pointer 可以改指向其他目標，reference 不能改。

    Session2 - C++ Review Handout.pdf p.23

    Q3. 沒有自行定義時，編譯器會自動產生哪 4 個方法？

    Default constructor、copy constructor、destructor、assignment operator。

    Session2 - C++ Review Handout.pdf p.41

    Q4. Destructor 有哪些特性？

    物件離開 scope 或被刪除時自動呼叫；名稱是 class 名加 ~；沒有回傳型別或回傳值；不接受參數；一個 class 只有一個。

    Session2 - C++ Review Handout.pdf p.40

    Q5. Dynamic binding 的優缺點？

    優點：理想的 data abstraction、OOP 的強大機制、廣泛用於大型軟體。缺點：效能下降，需要額外記憶體存 virtual function table，存取時有額外成本。

    Session2 - C++ Review Handout.pdf p.53
