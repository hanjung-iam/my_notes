    重點摘要

    • Binary tree 第 \(i\) 層最多 \(2^{i-1}\) 個節點，深度 \(k\) 最多 \(2^k-1\) 個節點；complete binary tree 適合用陣列表示（parent = \(i/2\)、left = \(2i\)、right = \(2i+1\)）。
    • 走訪：Inorder（左→根→右）、Preorder（根→左→右）、Postorder（左→右→根）用 stack；Level-order 用 queue。
    • Max heap：complete binary tree 且 parent ≥ child；插入往上比、刪除（永遠刪 root）往下 trickle down，時間都跟樹高有關。
    • BST：左子樹 < root < 右子樹，inorder 走訪得到排序結果；search / insert / delete 都是 \(O(h)\)，\(h\) 介於 \(\log_2 n\) 與 \(n\)。
    • Disjoint sets：用樹表示，Union \(O(1)\)；加上 weighting rule 與 collapsing rule 讓 \(n-1\) 次 union 與 \(n\) 次 find 為 \(O(n\cdot\alpha(n))\)。

    1. 樹的定義與術語

    樹結構把資料以階層方式組織。Tree 是一個或多個節點的有限集合：有一個 root；其餘節點可分成 \(n\) 個互斥集合 \(T_1,T_2,\dots,T_n\)（\(n\ge 0\)），每個 \(T_i\) 也是一棵樹（稱為 root 的 subtree）。

    術語定義
    Degree of a node該節點的 subtree 數
    Leaf / Terminal nodedegree 為 0 的節點
    Internal node至少有一個 child、且不是 root 的節點
    Degree of a tree樹中所有節點 degree 的最大值
    Sibling同一個 parent 的 children
    Ancestors從 root 到該節點路徑上的所有節點
    Descendants該節點所有 subtree 中的節點
    LevelLevel(root) = 1；parent 的 level 為 \(l\) 時，節點的 level 為 \(l+1\)
    Height / Depth of a tree樹中節點的最大 level

    樹的表示法

    • List representation：每個節點有一個 data 欄位與數個 link 欄位；degree 為 \(k\) 的樹，每個節點配置 \(k\) 個 link。
    • Left Child-Right Sibling representation：每個節點恰好兩個 link：left link 指向最左邊的 child，right link 指向最近的 sibling。把它順時針轉 45° 就成為一棵 degree-2 tree（binary tree）。

    Session6-Trees Handout.pdf p.3–10

    2. Binary Tree

    Binary tree 是一個有限節點集合：可以是空的，或由一個 root 加上兩棵互斥的 binary tree（left subtree、right subtree）組成。左右是有區別的：同樣的樹，可能是不同的 binary tree。

    💡
    最多節點數 第 \(i\) 層最多 \(2^{i-1}\) 個節點；深度 \(k\) 的 binary tree 最多 \[1+2+2^2+\cdots+2^{k-1}=2^k-1\] 個節點。
    特殊的 binary tree定義
    Skewed tree全部偏向左邊或右邊
    Full binary tree深度 \(k\) 且有 \(2^k-1\) 個節點
    Complete binary tree深度 \(k\)、\(n\) 個節點，且節點恰好對應到 full binary tree 中編號 1 到 \(n\) 的節點

    Binary Tree 的表示法

    Array representation：依 full binary tree 的編號存進一維陣列，節點 \(i\) 放在位置 \(i\)（array[0] 不用）：

    位置公式不存在的條件
    Parent(\(i\))\(i/2\)\(i=1\) 時是 root，沒有 parent
    leftChild(\(i\))\(2i\)\(2i>n\) 時沒有 left child
    rightChild(\(i\))\(2i+1\)\(2i+1>n\) 時沒有 right child
    • 優點：很容易求出 parent、left child、right child 的位置。
    • 缺點：skewed tree 浪費空間；插入、刪除節點需要搬動大部分既有節點（為了維持順序）。
    • Linked representation：每個節點有三個欄位 data、leftChild、rightChild。

    Session6-Trees Handout.pdf p.12–22

    3. Binary Tree 走訪

    每個節點恰好拜訪一次，並以相同方式處理每個節點與它的 subtrees。

    走訪順序運算式樹 A / B * C * D + E 的結果實作
    Inorderleft → root → rightA / B * C * D + EStack
    Preorderroot → left → right+ * * / A B C D EStack
    Postorderleft → right → rootA B / C * D * E +Stack
    Level-order由上到下、由左到右—Queue
     
    遞迴 Inorder（C++，Preorder / Postorder 只是改變 Visit 的位置）template <class T>
void Tree<T>::Inorder(TreeNode<T>* currentNode)
{ // Recursive inorder traversal function
    if(currentNode){
        Inorder(currentNode->leftChild);
        Visit(currentNode); // e.g., printout information
        Inorder(currentNode->RightChild);
    }
}
    非遞迴 Inorder（C++，使用 stack）template < class T >
void Tree<T>::NonrecInorder()
{ // Non recursive inorder traversal using stack
    Stack<TreeNode<T>*> s;    // declare and init a stack
    TreeNode<T>* currentNode = root;
    while(1){
        while(currentNode){ // move down leftChild field
            s.Push(currentNode); // add to stack
            currentNode = currentNode->leftChild;
        }
        if(s.IsEmpty()) return; // all nodes are visited
        currentNode = s.Top();
        s.Pop();
        Visit(currentNode);     // e.g., printout information
        currentNode = currentNode->rightNode;
    }
}

    把同樣的邏輯包成 nested class InorderIterator，每次呼叫 Next() 回傳下一個 inorder 元素。

    Level-Order（C++，使用 queue）template <class T>
void Tree<T>::LevelOrder()
{ // Traverse the binary tree in level order
    Queue<TreeNode<T>*> q;
    TreeNode<T>* currentNode = root;
    while(currentNode){
        Visit(currentNode);
        if(currentNode->leftChild) q.Push(currentNode->leftChild);
        if(currentNode->rightChild) q.Push(currentNode->rightChild);
        if(q.IsEmpty()) return;
        currentNode = q.Front();
        q.Pop();
    }
}

    講義自學主題：非遞迴與 iterator 版的 Preorder / Postorder、複製 binary tree、測試兩棵樹是否相等。

    4. Heap 與 Priority Queue

    Heap 是 complete binary tree，且 parent 的值：

    • ≥ child 的值 → Max Heap
    • ≤ child 的值 → Min Heap

    因為是 complete binary tree，可以直接用 array representation。

    Max Heap：Insert

    1. 插入新節點，維持 complete binary tree
    2. 若新節點比 parent 大，兩者交換；重複直到不再比 parent 大
    MaxPQ::Push（C++）template < class T >
void MaxPQ<T>::Push(const T& e)
{ // Insert e into max heap
  // Make sure the array has enough space here…
    int currentNode = ++heapSize;
    while(currentNode != 1 && heap[currentNode/2] < e)
    { // Swap with parent node
        heap[currentNode]=heap[currentNode/2];
        currentNode /= 2; // currentNode now points to parent
    }
    heap[currentNode]=e;
}

    時間：最多走過樹的高度。

    Priority Queue 與 Max Heap：Delete

    Priority queue：被刪除的是優先權最高的元素。應用：job scheduling、緊急服務、航管、客服、load balancing、交通管理、作業系統核心等。

    1. 永遠刪除 root
    2. 把最後一個元素移到 root（維持 complete binary tree）
    3. 與較大的 child 交換（若有）
    4. 重複步驟 3，直到滿足 max heap（trickle down）
    MaxPQ::Pop（C++）template < class T >
void MaxPQ<T>::Pop()
{ //Delete max element
    if(IsEmpty()) throw "Heap is empty";
    heap[1].~T(); // delete max element (always the root!)
    // Remove the last element from heap
    T lastE = heap[heapSize--];
    // trickle down
    int currentNode = 1; // root
    int child = 2;       // A child of currentNode
    while(child <= heapSize) {
        // Set child to larger child of currentNode
        if (child < heapSize && heap[child] < heap[child + 1]) child++;
        // Can we put lastE in currentNode?
        if (lastE >= heap[child]) break; // Yes!
        // No!
        heap[currentNode] = heap[child]; // Move child up
        currentNode = child; child *=2;  // Move down a level
    }
    heap[currentNode] = lastE;
}

    時間 = 樹的高度。

    💡
    Heap 的時間複雜度 Insert：\(O(\log n)\)（p.41）；Delete：\(O(\log n)\)（p.44）。

    5. Binary Search Tree (BST)

    BST 是滿足以下條件的 binary tree：

    • 每個元素都有 key，且沒有兩個元素的 key 相同
    • 左子樹的 key 都比 root 小；右子樹的 key 都比 root 大
    • 左右子樹也都是 BST
    💡
    重點 對 BST 做 inorder 走訪，會得到排序好的串列。

    搜尋機制通常要支援：搜尋元素、搜尋第 \(r\) 小的元素、插入、刪除最大/最小、刪除任意元素。

    Search

    從 root 開始比較：比 root 小就搜尋左子樹、比 root 大就搜尋右子樹；重複直到找到 key 或走到 leaf。

    BST::Get 迭代版（C++）template < class K, class E >
pair<K,E>* BST<K,E>::Get(const K& k)
{
    TreeNode < pair<K, E> > *currentNode = root;
    while (currentNode) {
        if (k < currentNode->data.first)
            currentNode = currentNode->leftChild;
        else if (k > currentNode->data.first)
            currentNode = currentNode->rightChild;
        else return & currentNode->data;
    }
    return NULL; // no match found
}

    Search by Rank

    • 節點的 rank = 它在 inorder 走訪中的位置；第 \(r\) 小的元素就是 rank 為 \(r\) 的節點。
    • 每個節點多存 leftSize = 1 + 左子樹節點數。
    • \(r<\) leftSize → 往左；\(r>\) leftSize → \(r\) 減去 leftSize 後往右；相等 → 找到。

    Insert

    先搜尋該元素是否存在；搜尋失敗時，就把元素插入在搜尋結束的位置。若 key 已存在，則更新它的值。

    Delete

    最小（最大）元素在最左邊（最右邊），不一定是 leaf，但最多只有一個 child。

    情況處理方式
    Case 1：要刪除的是 leaf把 parent 對應的 child 欄位設為 NULL，釋放節點
    Case 2：非 leaf，只有一個 child讓 parent 的指標改指向那唯一的 child，釋放節點
    Case 3：非 leaf，有兩個 children用最接近的元素取代：右子樹最小的元素或左子樹最大的元素

    時間複雜度

    • Search、insert、delete 都是 \(O(h)\)，\(h\) = BST 的高度。
    • Worst case \(h=n\)：例如依序插入 1, 2, 3, 4, …
    • Best case \(h=\log_2 n\)：例如依序插入 4, 2, 6, 1, 3, 5, 7
    • BST 的形狀取決於元素插入與刪除的方式。

    Session6-Trees Handout.pdf p.46–60

    6. Forests

    Forest：\(n\ge 0\) 棵互斥樹的集合。

    • 轉成 binary tree：每棵樹用 left child-right sibling 方式轉成 binary tree，再把 \(T_1\) root 的 rightChild 設為 \(T_2\) 的 root，依此串接。
    • Forest traversal：binary tree \(T\) 的 preorder 走訪，等同於對 forest \(F\) 做 forest preorder（先 root，再左邊的 forest，再右邊的 forest）。例：A B C D E F G H I。

    Session6-Trees Handout.pdf p.62–64

    7. Disjoint Sets

    集合 \(S=\{0,1,\dots,n-1\}\) 分成數個子集 \(S_1,\dots,S_k\)，且 \(S_i\cap S_j=\emptyset\)（\(i\ne j\)）。操作：

    • Union(\(S_i,S_j\))：\(S_i=S_i\cup S_j\) 或 \(S_j=S_i\cup S_j\)
    • Find(\(x\))：找出包含 \(x\) 的集合
    📝
    例子 \(S=\{0,1,2,3,4,5\}\)，\(S_1=\{0,2,3\}\)、\(S_2=\{1\}\)、\(S_3=\{4,5\}\)。Union(\(S_1,S_2\)) = \(\{0,1,2,3\}\)；Find(5) = 3。
    表示法做法FindUnion
    Array（sequential mapping）index = 集合成員，值 = 集合名稱，例：S = [1, 2, 1, 1, 3, 3]直接查表，\(O(1)\)掃描整個陣列，把值為 \(j\) 的改成 \(i\)
    Tree每個子集是一棵樹，以 root 代表集合；用陣列存 parent，root 存 −1。例：T = [−1, −1, 0, 0, −1, 4]從 \(x\) 沿 parent 往上找，直到 parent 為 −1把一個 root 的 parent 設為另一個 root，\(O(1)\)
    ❗
    最壞情況 \(S_1=\{0\},\dots,S_n=\{n-1\}\)，依序執行 Union(\(S_2,S_1\))、Union(\(S_3,S_2\))、…、Union(\(S_n,S_{n-1}\))，會形成一條長鏈；之後再執行 Find(0)、Find(1)、…、Find(\(n-1\)) 會很慢。

    改進一：Weighting rule（Union）

    不要總是把第二個集合併到第一個，而是把小的併到大的：

    \[S_i=S_i\cup S_j\ \text{ if } |S_i|\ge|S_j|,\qquad S_j=S_i\cup S_j\ \text{ if } |S_i|<|S_j|\]

    例：Union(1, 2)、Union(3, 4)、Union(5, 6)、Union(7, 8)、Union(1, 3)、Union(5, 7)、Union(1, 5) 這個序列會產生高度 \(\log n\) 的樹。

    改進二：Collapsing rule（Find）

    若 \(j\) 是從 \(i\) 到 root 路徑上的節點，就把 parent[\(j\)] 直接設成 root(\(i\))。

    💡
    結果 \(n-1\) 次 union 與 \(n\) 次 find 的總時間為 \(O(n\cdot\alpha(n))\)，平均 \(\alpha(n)\le\log n\)。

    Session6-Trees Handout.pdf p.66–78

    自我測驗

    Q1. 深度 \(k\) 的 binary tree 最多有幾個節點？什麼是 complete binary tree？

    \(2^k-1\) 個。深度 \(k\)、\(n\) 個節點的 binary tree，若節點恰好對應 full binary tree 中編號 1 到 \(n\) 的節點，就是 complete binary tree。

    Session6-Trees Handout.pdf p.13, p.16

    Q2. 用陣列表示 binary tree 時，節點 \(i\) 的 parent、left child、right child 在哪裡？

    Parent 在 \(i/2\)（\(i\ne 1\)）、left child 在 \(2i\)（\(2i\le n\)）、right child 在 \(2i+1\)（\(2i+1\le n\)）。

    Session6-Trees Handout.pdf p.19

    Q3. 哪一種走訪要用 queue 實作？

    Level-order；Preorder、Inorder、Postorder 用 stack。

    Session6-Trees Handout.pdf p.33

    Q4. 從 max heap 刪除元素的步驟？

    刪除 root → 把最後一個元素移到 root → 與較大的 child 交換 → 重複直到滿足 max heap（trickle down）。

    Session6-Trees Handout.pdf p.43

    Q5. BST 刪除有兩個 children 的節點時，要用哪個元素取代？

    最接近的元素：右子樹中最小的元素，或左子樹中最大的元素。

    Session6-Trees Handout.pdf p.59

    Q6. Disjoint sets 的 weighting rule 和 collapsing rule 分別是什麼？

    Weighting rule：Union 時把較小的集合併到較大的集合。Collapsing rule：Find 時把路徑上每個節點的 parent 直接設為 root。

    Session6-Trees Handout.pdf p.76, p.78
